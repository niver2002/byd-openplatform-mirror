12.获取空调各区域温度

输入参数

数据类型字段名称值描述
intarea区域AC_TEMPERATURE_MAIN主驾驶温度
intarea区域AC_TEMPERATURE_DEPUTY副驾驶温度
intarea区域AC_TEMPERATURE_REAR后空调
intarea区域AC_TEMPERATURE_OUT车外温度

返回值

数据类型名称值描述
int空调各区域温度[AC_TEMP_IN_CELSIUS_MIN,AC_TEMP_IN_CELSIUS_MAX]℃;AC_TEMP_IN_CELSIUS_MAX] ℃;
[AC_TEMP_IN_FAHRENHEIT_MIN,AC_TEMP_IN_FAHRENHEIT_MAX]℉		车内主副驾温度：
1 )当温度单位为摄氏温 度℃时(默认)：范围：[17，33] ；
2 )当温度单位为华氏温度℉时：范围[64，91]。
int空调各区域温度[AC_TEMP_OUT_CELSIUS_MIN,AC_TEMP_OUT_CELSIUS_MAX]℃;
[AC_TEMP_OUT_FAHRENHEIT_MIN,AC_TEMP_OUT_FAHRENHEIT_MAX] ℉		车外温度：
1 )摄氏单位:温度范围[-40℃， 50℃] ；
2 )华氏单位: [-40℉， 122℉]。
