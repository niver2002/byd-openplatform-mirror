媒体中心类

1.方法概要

类 BYDAutoMultimediaDevice
public class BYDAutoMultimediaDevice
限定符和返回类型方法描述
static BYDAutoMultimediaDevicegetInstance(Context con)获取实例
intgetMediaType()获取播放类型

备注：该类针对的是车载多媒体自带的媒体中心，包括音视频播放、广播、蓝牙音乐等功能。


2.获取播放类型

API 名称int getMediaType()
接口描述获取播放类型
输入参数无

返回值

数据类型名称值描述
int播放类型MULTIMEDIA_TYPE_AMAM
int播放类型MULTIMEDIA_TYPE_FMFM
int播放类型MULTIMEDIA_TYPE_CDCD
int播放类型MULTIMEDIA_TYPE_VCDVCD
int播放类型MULTIMEDIA_TYPE_DVDDVD
int播放类型MULTIMEDIA_TYPE_TVTV
int播放类型MULTIMEDIA_TYPE_AUDIO_OFFAudio Off (音响关闭 )
int播放类型MULTIMEDIA_TYPE_AUXAUX
int播放类型MULTIMEDIA_TYPE_USB_AUDIOUSB 音频
int播放类型MULTIMEDIA_TYPE_USB_VIDEOUSB 视频
int播放类型MULTIMEDIA_TYPE_SD_AUDIOSD 音频
int播放类型MULTIMEDIA_TYPE_SD_VIDEOSD 视频
int播放类型MULTIMEDIA_TYPE_HD_AUDIOHD ( 硬盘) 音频
int播放类型MULTIMEDIA_TYPE_HD_VIDEOHD ( 硬盘) 视频
int播放类型MULTIMEDIA_TYPE_LOCAL_AUDIO本地音频
int播放类型MULTIMEDIA_TYPE_LOCAL_VIDEO本地视频
int播放类型MULTIMEDIA_TYPE_BT蓝牙音乐
int播放类型MULTIMEDIA_TYPE_ROBOTRobot
int播放类型MULTIMEDIA_TYPE_INVAID无效

备注：媒体中心未启动，或者被用户从近期任务清除，则返回MULTIMEDIA_TYPE_INVAID否则返回媒体中心当前的播放类型。

播放类型随不同车型变化。


3.获取播放模式

API 名称int getPlayMode()
接口描述获取播放模式
输入参数无

返回值

数据类型名称值描述
int播放模式MULTIMEDIA_PLAY_MODE_SINGLE_REPEAT单曲重复播放
int播放模式MULTIMEDIA_PLAY_MODE_RANDOM随机播放
int播放模式MULTIMEDIA_PLAY_MODE_PREVIEW预览播放
int播放模式MULTIMEDIA_PLAY_MODE_SCANSCAN 状态
int播放模式MULTIMEDIA_PLAY_MODE_STEREO广播播放立体声频道
int播放模式MULTIMEDIA_PLAY_MODE_ALL_REPEAT全部重复播放
int播放模式MULTIMEDIA_PLAY_MODE_INVAID无效

备注：媒体中心未启动，或者被用户从近期任务清除，则返回

MULTIMEDIA_PLAY_MODE_INVAID，

否则返回媒体中心当前的播放模式。

FM： MULTIMEDIA_PLAY_MODE_STEREO

Music: MULTIMEDIA_PLAY_MODE_SINGLE_REPEAT/MULTIMEDIA_PLAY_MODE_RANDOM/MULTIMEDIA_PLAY_MODE_ALL_REPEAT

Video: MULTIMEDIA_PLAY_MODE_ALL_REPEAT


4.获取播放状态

API 名称int getPlayState()
接口描述获取播放状态
输入参数无

返回值

数据类型名称值描述
int播放状态MULTIMEDIA_STATE_PLAY播放
int播放状态MULTIMEDIA_STATE_PAUSE停止
int播放状态MULTIMEDIA_STATE_STOP暂停

备注：媒体中心未启动，或者被用户近期任务清除，则返回停止，否则返回媒体中心当前的播放状态。

对于不同播放类型，返回结果有以下区别：

Music (本地，U 盘，蓝牙)：播放，暂停。

Video(本地，U 盘)： 播放，暂停。

FM ：播放，停止。


5.获取当前播放的音视频信息

API 名称MediaInfo getPlayMediaInfo()
接口描述获取当前播放的音视频信息
输入参数无

返回值

数据类型名称值描述
MediaInfoString fileName文件名称
MediaInfoString artistName歌手名称
MediaInfoString albumName专辑名称

备注：媒体中心未启动，或者被用户从近期任务清除，返回 NULL。

媒体中心占据音频焦点时，根据当前的媒体中心类型返回相应信息

FM: 返回空

Music: 返回音频名称，艺术家名称(没有则为空)，专辑名称(没有则为空)。

Video: 返回视频名称，艺术家和专辑为空。

其他应用占据音频焦点时，返回 NULL。


6.媒体中心控制

API 名称int controlMedia(int mode,int action,MediaControlParam param)
接口描述控制音乐、视频、收音机

输入参数

数据类型名称值描述
intmodeMODE_RADIOFM
intmodeMODE_MUSIC音乐
intmodeMODE_VIDEO视频
intactionACTION_ENTER打开媒体中心
intactionACTION_PLAY播放音乐/视频，收听 FM
intactionACTION_PAUSE暂停音乐/视频，FM 无暂停
intactionACTION_PLAY_PRE音乐/视频播放上一首，FM 搜索上一台
intactionACTION_PLAY_NEXT音乐/视频播放下一首，FM 搜索下一台
intactionACTION_SET_PLAY_PATTERN音乐设置播放模式(循环 ，随机， 单曲)， 视频设置全屏半屏播放
intactionACTION_AUTO_SEARCHFM 自动搜台
intactionACTION_CANCEL_RADIO_SEARCHFM 停止搜台
数据类型名称值描述
MediaControlParamparamPARAM_SOUR CESOURCE_LOCAL本地音乐/视频
MediaControlParamparamPARAM_SOUR CESOURCE_USBU 盘音乐/视频
MediaControlParamparamPARAM_SOUR CESOURCE_SDSD 音乐/视频
MediaControlParamparamPARAM_SOUR CESOURCE_BTMUSIC蓝牙音乐
MediaControlParamparamPARAM_PATTE RNPATTERN_CYCLE音乐全部
MediaControlParamparamPARAM_PATTE RNPATTERN_RANDOM音乐随机
MediaControlParamparamPARAM_PATTE RNPATTERN_SINGLE音乐单曲
MediaControlParamparamPARAM_PATTE RNPATTERN_HALF_SCREEN视频半屏播放
MediaControlParamparamPARAM_PATTE RNPATTERN_FULL_SCREEN视频全屏播放
MediaControlParamparamPARAM_RADIO_FREQFM 频道值，int类型FM 频道值
MediaControlParamparamPARAM_FILE_NAME歌曲/视频名称，string 类型歌曲/视频名称
MediaControlParamparamPARAM_ARTIST_NAME艺术家名称，string 类型歌曲所属艺术家名称

返回值

数据类型名称值描述

针对不同的mode+action, param 可以填充一项或者多项，也可以不填充。
