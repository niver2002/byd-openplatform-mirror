## **文件传输概述**

**1. 文件传输适用场景**

文件传输服务 ftx 用于传输超过单条消息承载能力的数据，典型场景包括：

- WiFi 配网凭据
- 配置文件（JSON/INI）
- 日志片段

### **2. 传输流程概览**

```
发送端 → ftx.send (首片)
         → 携带 fid + fname + ftype + enc_mode + iv + tag + data
接收端 → ACK (result=0 成功 / result=1 重传)
发送端 → ftx.send (中间片)
        → 携带 fid + frag_index + data
接收端 → ACK
发送端 → ftx.send (末片)
接收端 → ftx.done 事件（传输完成）
```
