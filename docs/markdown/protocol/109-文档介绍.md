# 文档介绍

> 来源：软件开发协议 / 直连接入协议 / 比亚迪智能设备开放接入协议 / 文档介绍 · https://openplatform.byd.com/#/document/index?id=109

### 1. 编写目的

本文档描述 IoT 设备接入座舱所需实现的 BLE GATT 协议及数据格式的设计说明。目的是：

1) 详细解析描述软件需求，作为用户和软件开发人员之间相互了解的基础；

2) 详细说明 IoT 设备接入的实现方案，作为软件结构设计和编码的基础；

3) 作为总体测试的依据和参考。

### 2. 文档范围

本文档涵盖以下内容：

• AutoIoT 协议的整体架构和核心概念；

• BLE 传输层的广播、GATT 服务定义；

• 物模型 Profile 的结构和字段定义；

• 消息交互的格式和操作语义；

• 编码格式（JSON/CBOR）的基本规则；

• 分片机制的基本流程；

• 安全等级的概述和选择指南；

• 文件传输、OTA 升级的流程概述；

• 错误码的格式和常见错误速查；

### 3. 读者对象

程序开发人员、产品经理、测试人员等。

### 4. 术语与缩写解释

协议统一使用简短的缩写字段命名（如 did 表示设备 ID，srvs 表示服务列表），以减少 JSON 体积、提高编码效率、保证命名一致性。
