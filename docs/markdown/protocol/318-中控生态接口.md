# 中控生态接口

> 来源：硬件接口规范 / 生态硬件接口 / 中控生态接口 · https://openplatform.byd.com/#/document/index?id=318

## **中控生态接口**

中控屏背面预留有5个生态接口，当搭载中控生态屏时，这些接口可作为后装设备的安装固定接口。当满足电气信号要求和PIN脚定义的设备正常接入时，在车机系统上电后就会为设备输出供电9V~16V/2A的供电，当这些接口未接入设备或短路时中控屏会自动切断供电，这些接口的供电也可以在智慧物联APP的页面中进行单独控制。

### **1. 结构安装**

#### **1.1 车端接口**

- 中控屏靠近主驾侧接口（Pogo4）承重能力≤400g，其他接口承重能力≤150g；
- 固定螺丝柱采用未攻穿结构，螺牙深度6mm；
- 接口pin针插入孔为通孔设计，外接件公端pin针插入孔位后与中控屏板卡漏铜处接触，实现通信&供电；
- 弹簧针安装孔与螺丝孔位中心距公差+0.08mm。

![image.png](../assets/d3ecfe5389a84d9eb572ba5fdb0c71cb-42bf34.png)

图 1-1 中控生态接口背视图

#### **1.2 外接件**

- 外接产品端弹簧针选型不做要求，针体采用黄铜材质，头部镀金（镀层厚≥0.08μm），保证螺丝拧紧至额定扭矩时，弹簧针与硬件触点面面接触、无虚接，且保证在正常压缩行程范围内；
- 配套螺丝统一为M4×8机牙螺丝（不可选用过长螺丝，会损伤屏幕本体），符合ISO 4762标准，拧紧扭矩标准化（2.5~3.0N·m），螺丝表面镀环保黑色锌镍合金≥3μm；
- 外接件设计开发应满足整车空间校核：

1）中控屏顶部外接件设计尺寸距离中控屏上边缘≤75.9mm；

2）中控屏左侧外接件设计尺寸距离方向盘拨杆≥25mm；

3）中控屏右侧外接件设计尺寸距离中控屏右边缘≤20mm。

### **2. 供电能力**

中控生态屏提供 5个生态接口，外接件未经书面同意不得擅自超出接口供电阈值；接口兼容性方面，外接件接入后应能与生态接口在电气特性、通讯协议、负载能力、保护特性等方面全兼容。

- 额定电压：12V （输出电压范围9V~16V）；
- 额定电流：2A（最大3A）；
- 过流保护：3.5A；
- 过压保护：18V；
- 输出控制：每一路生态接口均具备独立的打开/关断能力；
- 总带载能力：额定：12V/9A / 最大：16V/9A。

### **3. 通讯方式**

中控生态接口提供1路插入检测的硬线通讯能力。

外接件可以采用蓝牙、Wi-Fi与车机通讯，其中蓝牙协议参考《比亚迪智能设备开放接入协议》,如有Wi-Fi通讯需求请提交工单与我方建联。

### **4. 电气接口**

电气接口由 5个 pin 引脚组成，分别承担电源、地、信号等基础电气功能，未经书面同意不得擅自更改引脚定义。接入中控生态接口后应能全部兼容，引脚接触电阻、绝缘电阻、耐压与插拔寿命应满足车载环境要求。

### **5. 注意事项**

中控生态接口开发者在开发产品前，请先阅读并遵守以下注意事项，以确保开发的生态设备能够满足中控生态接口的要求，充分发挥中控生态接口的性能，并能在比亚迪中控生态接口上正确和安全使用：

- 中控生态接口不具备防水功能，外接件应满足干燥的要求，避免进水短路损害中控生态接口；
- 中控生态接口具备插入检测功能，根据插入检测DET引脚不同下拉电阻阻值进行外接件分类，外接件插入检测DET引脚下拉电阻应满足外接件分类定义的阻值要求；
- 中控生态接口具备带电插拔功能，外接件应满足带电插拔的要求；
- 接口（Pogo4）承重能力≤400g，其他接口承重能力≤150g。
