> 来源：软件开发协议 / 云接入协议 / 比亚迪智能云设备接入协议 · https://openplatform.byd.com/#/document/index?id=279

## **比亚迪智能云设备接入协议**

### **1. 协议概述**

在比亚迪车机系统中，通过集成 OAuth2 协议，实现与第三方云设备的安全控制与交互，从而支撑物联网（IoT）业务能力。OAuth2 作为一种广泛采用的授权协议，常用于第三方登录场景，使用户无需重复注册账号，即可快速访问网站或应用的功能与服务。该协议通过颁发访问令牌（Access Token）的方式，代替用户凭证进行授权，保障了用户隐私和数据安全，同时提升了系统的可扩展性与易用性。

比亚迪云设备接入，通过近场蓝牙授权对接方式，实现与第三方云设备的安全控制。

#### **1.1 适用场景**

适用场景：在比亚迪车机上实现与三方智能云设备的控制与交互，支撑IoT领域的业务能力。

#### **1.5 签名**

##### **1.5.1 签名方式**

先把请求参数param拼接成字符串str。然后使用str和密钥在进行签名，生成签名值Signature，签名值放入请求head中。

详细流程：先把请求参数param中参数为空的字段，移除。请求参数按照请求字段的ascll码的升序进行排序，然后按照key=value&key=value&key=value的方式进行拼接成str。

##### **1.5.2 支持签名算法**

当前仅支持HMAC-SHA256签名算法。

##### **1.5.3 接口范围**

本文档2.2章节、2.3章节接口的head中Signature值，需要使用该方法进行签名。

/**
 * 删除value值为空的数据
 */
private static Map paramIgnoreNull(Map parameters) {
    if (EmptyUtil.isEmpty(parameters)) {
        return parameters;
    }
    Set set = parameters.keySet();
    Map map = new HashMap();
    set.stream().forEach(key -> {
        Object o = parameters.get(key);
        if (EmptyUtil.isNotEmpty(o) && EmptyUtil.isNotEmpty(o.toString())) {
            map.put(key, o);
        }
    });
    return map;
}
```

 /**
  * 拼接字符串
  */
 public static String paramToStr(Map parameters, String separator) {
     if (EmptyUtil.isEmpty(parameters)) {
         return Constant.BLANK_STR;
     }
     StringBuffer sb = new StringBuffer();
     //已经排序好处理
     if (parameters instanceof SortedMap) {
         parameters.keySet().stream().forEach(key -> {
             sb.append(key).append("=").append(parameters.get(key).toString().trim()).append(separator);
         });
         if (EmptyUtil.isNotEmpty(sb, separator)) {
             sb.deleteCharAt(sb.length() - 1);
         }
         return sb.toString();
      }
      //未排序须处理
      List<String> keys = new ArrayList<String>(parameters.keySet());
       //排序
      Collections.sort(keys);
      keys.stream().forEach(key -> {
          sb.append(key).append("=").append(parameters.get(key)).append(separator);
      });
      if (EmptyUtil.isNotEmpty(sb)) {
          sb.deleteCharAt(sb.length() - 1);
      }
      return sb.toString();
 }
```

###### **1.5.4.3 生成签名/验签**

以下为代码示例，可根据自身情况进行调整，验证。

```
import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import java.util.Base64;

/**
 * 生成签名和验签
 */
public class HMACSHA256Util {

    private static final String HMAC_SHA256_ALGO = "HmacSHA256";

    /**
     * 使用HMAC-SHA256算法生成消息签名
     */
    public static String generateSignature(String data, String key) throws Exception {
        Mac sha256_HMAC = Mac.getInstance(HMAC_SHA256_ALGO);
        SecretKeySpec secret_key = new SecretKeySpec(key.getBytes("UTF-8"), HMAC_SHA256_ALGO);
        sha256_HMAC.init(secret_key);

        byte[] hash = sha256_HMAC.doFinal(data.getBytes("UTF-8"));
        return Base64.getEncoder().encodeToString(hash);
    }

    /**
     * 验证给定的消息签名是否正确
     */
    public static boolean verifySignature(String data, String key, String signature) throws Exception {
        String calculatedSignature = generateSignature(data, key);
        return calculatedSignature.equals(signature);
    }

    public static void main(String[] args) {
        try {
            // 这里替换为你的密钥
            String key = "1XGjLQHDKqymSYzfkReVaOgpt4xrBNF2";
            // 这里替换为你的消息
            String message = "The quick brown fox jumps over the lazy dog";

            // 生成签名
            String signature = generateSignature(message, key);
            System.out.println("Generated HMAC-SHA256 Signature: " + signature);

            // 验证签名
            boolean isVerified = verifySignature(message, key, signature);
            System.out.println("Is the signature verified? " + isVerified);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```
