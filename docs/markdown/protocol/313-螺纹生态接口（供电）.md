# 螺纹生态接口（供电）

> 来源：硬件接口规范 / 生态硬件接口 / 螺纹生态接口（供电） · https://openplatform.byd.com/#/document/index?id=313

## **螺纹生态接口（供电）**

螺纹生态接口是为后装产品提供供电和固定功能的前装接口，固定方式为1/4螺纹，供电结构为POGO PIN，电压9V~16v，解决车内后装产品常规采用的胶粘安装及甩线供电痛点，为后装产品提供媲美前装的使用体验。接口使用自恢复式短路保护方式，解决传统保险丝方案熔断后需要更换新件的体验问题，提升了车内接口使用便利性及可靠性。

### **1. 结构安装**

#### **1.1 车端接口**

- 严格遵循ISO 688-1/4"-20 UNC统一标准粗牙螺纹，牙型角60°，螺距1.27mm，中径公差4H，大径公差6H，螺纹有效旋合长度≥6mm；
- 螺纹底座采用粉末冶金加工成型+拉丝(圆形 CD 纹)+PVD 电镀+防指纹（AF）处理，基材为SUS17-4PH（马氏体沉淀硬化不锈钢），螺纹底座与座舱仪表台内饰板采用自攻螺丝+BOSS柱/金属弹片连接，无间隙变形；
- 螺纹接口集成机械固定+供电一体化功能，PIN点表面低于接触端面0.5mm，保证绝缘。

#### **1.2 外接件**

- 外接产品端弹簧针选型不做要求，单针工作高度的压缩弹力最小为1.5N，单针最大工作高度的压缩弹力最小为1.0N，针体采用黄铜材质，头部镀金（镀层厚≥0.25μm），安装工作后需保证在压缩行程范围内，保证螺丝拧紧至额定扭矩时，弹簧针与硬件触点面面接触、无虚接；
- 弹簧针行程要求＞2mm；
- 产品定位孔朝向车头方向左右夹角60度范围内，外接件可以依据定位孔设计产品目标方向；
- 拓展接口安装面与水平面可能存在20度以内水平倾角，外接件设计时应保有相关安装适应性；
- 外接件总重＜300g。

### **2. 供电能力**

螺纹生态接口提供 1个1/4"标准螺纹+PIN点供电的形式，外接件未经书面同意不得擅自超出接口供电阈值；外接件接入后应能与车机在电气特性、通讯协议、负载能力、保护特性等方面全兼容。

- 额定电压：12V （输出电压范围9V~16V）；
- 额定电流：3A（最大4A）；
- 过流保护：5A；
- 过压保护：18V；
- 过流保护动作时间：＜50ms；
- 自恢复性能：大部分域控供电车型具备自恢复能力，个别车型使用保险丝保护；
- 输出控制：跟随整车上下电。

### **3. 通讯方式 **

暂无硬线通讯。

外接件也可以采用蓝牙、Wi-Fi与车机通讯，其中蓝牙协议参考《[比亚迪智能设备开放接入协议](#/researchTools/developAgreement)》，如有Wi-Fi通讯需求请[提交工单](#/personal/work-order)与我方建联。

### **5. 注意事项**

- 产品外轮廓尺寸原则上不超过50*50*50mm，更大尺寸则应设计相应的旋转支架结构，以使用户可以自行找到合适安装位置。
- 螺纹生态接口承重＜300g。
