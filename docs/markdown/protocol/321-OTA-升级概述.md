## **OTA 升级概述**

### **1. OTA 流程概览**

OTA 升级分四个阶段：

```
1. 开始传包 (ota.start)
→ 通知设备目标版本、总帧数、校验码
→ 设备预检（电量、空间、是否在使用）

2. 发送数据 (ota.send_data)
→ 逐帧发送固件数据
→ 设备逐帧确认

3. 设备激活
→ 校验固件 → 重启 → 分区激活（A/B 或备份）

4. 上报结果 (ota.report)→ 重新连接后查询升级结果
```
