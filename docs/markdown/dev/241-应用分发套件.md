## **车机API库**

比亚迪面向车机应用开发者，全面开放车内标准化接口服务。比亚迪已将整车信号与座舱能力统一封装为数百项标准化 API 接口，依托成熟的技术体系与安全规范，为开发者提供稳定、高效、统一的开发基座。广大开发者可借助官方开放接口，便捷调用车辆数据与座舱能力，在比亚迪生态开放平台上高效开发、深度适配各类车机应用，丰富座舱场景体验。同时，为了保障三方应用在车机端安全运行，请您通过[**比亚迪生态开放平台**](#/dashboard/analysis)-应用分发业务完成应用的[**接入**](21-接入指南.html)。

车机开放API内容包括：车身状态、行驶数据、车速、能量模式、全景摄像头、空调、 空气质量、发动机、变速箱制动、门锁、车灯、安全带、雷达、充电、轮胎、仪表、时间、车辆设置、传感器、媒体中心等 20+类数据。各模块主要通过查询（get）、控制（set）、监听三种方式开放数据。 查询（get）用于获取车辆状态数据， 控制（set）用于控制车辆和更改车辆设置项， 监听可以实时获取各模块数据的变化。其中 set 接口的返回值，仅表示命令下发是否成功，需要通过监听接口确定设置是否成功。

如需查询接口详细定义，或获取对应jar包，请通过认证后访问：【**管理中心-应用分发-开发工具-**[**API库**](#/developTools/apiLib)】
