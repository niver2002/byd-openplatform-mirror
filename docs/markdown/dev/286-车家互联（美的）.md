## **『美的』车家互联**

### **1. 合作简介**

比亚迪车家互联与美的合作，以车为核心，将车辆能力与智能家居深度整合，从用户出行前、离家后、出行中、回家前、回家后等场景，挖掘汽车和智能家居两个空间的空间交互场景，打破“车”、“家”两大生活空间的边界和壁垒，实现跨空间设备控制、车与家居设备跨空间智能化联动，为车主、用户提供更加便捷、智能、高效的生活体验。

视频 1-1 车家互联

车家互联分为车控家、家控车两部分：

- 车控家：支持通过比亚迪车辆控制10类家居设备：空调、厨房空调、灯、窗帘、电热水器、扫地机器人、取暖器、空净、新风；
- 家控车：开放车辆部分能力和数据给美的，支持通过家居中控、语音和应用查看、控制车辆。

车控家，即AIoT业务的云云对接——云云接入。

### **3. 家控车**

家控车，即车云端API开放能力的应用。

#### **3.1 家居中控屏控制**

美的智慧家居中控屏，可远程查看和控制已授权的比亚迪车辆，如下图 3-1、3-2，具体包括：

- 车辆基础信息：车型、车辆昵称、车体图
- 车辆状态：续航、里程、油电量、门锁门窗、胎压、车辆健康
- 远程控制：闭锁、闪灯鸣笛、关窗、开空调、通风加热、导航下发到车

#### **3.3 家居中控屏消息通知**

家居中控屏会收到车的消息、告警通知，例如结束充电、门窗未关未锁、车辆遗留检测、车辆碰撞提醒报警。
