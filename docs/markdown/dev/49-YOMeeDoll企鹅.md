## **YOMeeDoll企鹅**

国产原创手作品牌YOMeeDoll企鹅，通过**微信表情包（累计发送量超30亿+）**、全平台二创（小红书话题浏览量超**5.6亿**、抖音播放量亿级），成为“治愈文化”的代表符号。

2026年，YOMeeDoll企鹅正式入驻比亚迪生态开放平台，双方基于其软萌、治愈形象共创车机主题，让小企鹅迅速成为车机里的新晋“萌宠搭子”。主题上线后，同步在比亚迪汽车、比亚迪智慧生态等官方账号渠道宣发，并多次登上**新车上市发布会**。首月主题累计**下载量突破20万**，**全渠道宣传曝光量超1亿**，覆盖数百万潜在车主用户。IP的影响力从线上表情包、手作玩偶延伸至驾车场景，实现了从潮玩圈到汽车出行场景的跨圈层品牌级曝光。
