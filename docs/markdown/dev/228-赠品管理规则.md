# 赠品管理规则

> 来源：营销渠道 / 规则中心 / 赠品管理规则 · https://openplatform.byd.com/#/document/index?id=228

##### **赠品管理规则**

###### **一、适用范围**

###### **1.1 适用对象**

本规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。

###### **1.2 适用范围**

第三方商家在比亚迪商城进行交易中如涉及附送赠品，需遵守本规则。本规则所称赠品，指由第三方商家提供并承担全部责任的合格商品，不包括比亚迪商城的自营商品。

###### **二、赠品管理细则**

2.1 第三方商家如赠送赠品，需对赠品的品种、规格、数量、价格等信息进行真实、清晰的描述，避免误导消费者。

2.2 第三方商家在商品描述中注明附送赠品，或虽未注明但与消费者协商确认附送赠品的，应按约定向消费者提供赠品。

2.3 赠品的发货时间应与交易商品承诺或约定的发货时间一致。

2.4 赠品需为质量合格的合规商品，不得使用侵犯他人知识产权、质量不合格、二手、国家法律法规禁止或比亚迪商城禁止发布的商品作为赠品。第三方商家如出现以上问题，将比亚迪商城将参照《第三方商家违规处理规则》进行处理。

2.5 若交易最终发生退货退款，消费者应确保赠品完好并随商品一并退回。因商家原因导致赠品需退回的，退货运费由商家承担；因消费者原因导致赠品无法退回，商家不得以此拒绝消费者的退货要求，但在处理退款时，可扣除赠品声明价值或市场公允价值对应的价款。

###### **三、附则**

3.1 规则变更：比亚迪商城有权根据业务需要或法律法规变化随时调整本规则。调整后的规则通过比亚迪生态开放平台向商家公示后生效。如商家不同意变更，可书面提出异议并停止使用相关服务；若商家在变更生效后继续使用服务，即视为接受变更后的规则。

3.2 生效时间：本规则于2026年1月1日首次发布，自2026年1月1日起正式生效。
