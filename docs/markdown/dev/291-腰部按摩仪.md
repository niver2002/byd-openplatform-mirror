## **『SKG』腰部按摩仪 G5**

SKG腰部按摩仪G5，通过蓝牙协议接入“智慧物联APP”。用户通过车机大屏或者车内语音助手，可以获取腰部按摩仪的按摩状态、电池电量显示等信息，以及控制按摩仪的按摩手法、按摩模式、热敷模式等，如下视频 1-1。

视频 1-1 腰部按摩仪

### **1. 车机大屏显示和控制**

车机大屏控制腰部按摩仪的功能有：

- 按摩时长调节；
- 按摩手法切换；
- 脉冲按摩/振动按摩/热敷模式强度调节；

### **2. 车机语音控制**

车机智能语音提示和控制腰部按摩仪的功能有：

- 电池电量播报；
- 按摩时长设置；
- 当前按摩手法播报和设置；
- 脉冲按摩/振动按摩/热敷模式播报和调节；
