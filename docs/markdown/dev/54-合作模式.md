## **合作模式**

### **1、合作范围**

比亚迪主题商店业务合作范围覆盖主题、动态主题、壁纸、动态壁等内容模块，企业或个人开发者设计开发出相关作品，上传到主题商店，测试审核通过后，上线至比亚迪销售平台下供消费者下载或购买。

### **2、合作方式**

2.1 主题开发者在比亚迪生态开放平台主题商店上传和管理作品。**主题开发者在上传作品时需勾选分成比例确认合作方式。**

2.2 比亚迪及其关联公司根据与开发者约定的授权范围分发和推广其作品，供最终用户在比亚迪销售平台下载和使用。开发者上传作品时需如实设置授权有效期。

2.3 我们根据与开发者的合作方式，将上线的主题作品收入在扣除手续费及一定比例的平台服务费率后结算给开发者。合作方式及平台服务费率如下：

|  |  |  |  |
|---|---|---|---|
| 合作方式 | 说明 | 平台服务费率 |  |
| 方式1 | 开发者负责主要内容设计，双方共同参与作品的开发、测试等环节 | 开发者负责主要内容设计，比亚迪负责内容审核、上架等工作，双方共同完成作品的开发、适配、测试等环节。 | 30% |
| 方式2 | 开发者将作品授权给比亚迪，在授权范围内，比亚迪独立创作，形成衍生作品 | 比亚迪在授权范围内独立创作，开发者提供基础素材、形象并授权等，不参与具体创作过程。 | 70% |
| 方式3 | 开发者与比亚迪共同负责内容设计，联合共创衍生作品 | 开发者提供素材、形象等并授权，双方共同参与作品的策划、内容设计、开发、适配、测试等环节，根据具体业务情况双方可联合宣发。 | 50% |

### **3、结算方式**

![票流.png](../assets/09e772a2825f428b8673f5932e223092-5823af.png)

图2-1 结算方式

**账期：**T日+20日 (T日：指用户通过销售平台购买上传作品或衍生作品并完成支付之日）

**手续费：**以不同渠道支付方式实际手续费为准。

**计算方式示例：**开发者选择5：5的分成方式（平台服务费率50%），用户实际支付9.9元购买主题（未退款），开发者实际到账=（9.9-手续费）*50%
