# 应用分发业务合规承诺

## **比亚迪应用分发业务合规承诺**

**在您开始使用我们的产品/服务前，请您务必先仔细阅读和理解本承诺，特别应重点阅读我们以粗体标识的条款，确保您充分理解和同意之后再开始使用。**

为维护用户合法权益、保障用户的个人信息安全可控，您作为开发者承诺您提供至比亚迪应用市场的应用将严格遵守《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》《App违法违规收集使用个人信息行为认定方法》《工业和信息化部关于开展信息通信服务感知提升行动的通知》《工业和信息化部关于进一步提升移动互联网应用服务能力的通知》及相关法律法规规定，遵守《比亚迪应用市场审核规范》及比亚迪开放平台的其他相关平台规则，并做出如下承诺：

### **1. 个人信息保护**

为保障用户权益与个人信息安全，开发者承诺提供的应用程序遵守《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》《汽车数据安全管理若干规定（试行）》《未成年人网络保护条例》《互联网信息服务算法推荐管理规定》《App违法违规收集使用个人信息行为认定方法》《关于开展APP侵害用户权益专项整治工作的通知》《工业和信息化部关于开展纵深推进APP侵害用户权益专项整治行动的通知》、《工业和信息化部关于进一步提升移动互联网应用服务能力的通知》《信息安全技术 个人信息安全规范》以及国家强制标准等相关规定和政策。

开发者保证其提供的应用（包括应用内使用的SDK）不存在以下侵犯用户权益的行为：

- 违规收集个人信息行为
- 超范围收集个人信息行为
- 违规使用个人信息行为
- 强制用户使用定向推送功能行为
- 强制、频繁、过度索取权限行为
- 频繁自启动和关联启动行为
- 欺骗误导强迫用户行为
- 欺骗误导用户提供个人信息行为
- 未提供账号注销功能或者账号注销难
- 未提供用户权利响应渠道
- 其他违反法律、行政法规规定侵犯用户权益的行为

### **2. 应用内容**

开发者承诺提供的应用程序遵守《中华人民共和国网络安全法》《互联网信息服务管理办法》《中华人民共和国民法典》《中华人民共和国刑法》《中华人民共和国枪支管理法》、《中华人民共和国国家安全法》《中华人民共和国计算机信息系统安全保护条例》《中华人民共和国广告法》以及国家强制标准等相关规定和政策。

开发者保证其提供的应用（包括应用内使用的SDK）不存在以下行为：

- 不得含有违法内容或其他敏感信息，包括但不限于涉政、涉赌、暴力、色情、性暗示及广告法中不允许使用的词汇；
- 不得带有诽谤、人身攻击或者侮辱个人或者团体；
- 不得对武器进行过于逼真的表述（如不能涉及武器的制造工艺和参数等），并鼓励违法或滥用武器；
- 不得存在反政府、反社会或者不符合主流政治、存在国家法律禁止的行为；
- 内容存在安全隐患、其他不友好信息或违规违法嫌疑信息；
- 实际内容与应用内描述或平台信息不符，构成虚假宣传或者误导用户。

### **3. 应用资质**

开发者承诺提供的应用程序遵守《中华人民共和国著作权法》《计算机软件保护条例》《互联网信息服务管理办法》《非经营性互联网信息服务备案管理办法》《反不正当竞争法》《互联网文化管理暂行规定》以及国家强制标准等相关规定和政策。

开发者保证其提供的应用遵循如下要求：

- 应用发布上架，需提供真实有效的《计算机软件著作权证书》（或《APP电子版权认证证书》）以及平台要求的其他资质文件；
- 应用发布上架，需按相关规定履行APP备案手续。未履行备案手续的，不得从事APP互联网信息服务；
- 应用内需在显著位置展示APP备案编号，并支持备案编号可点击跳转至备案系统供用户查询；
- 应用应保证具有从事相关行业的资质，资质要求可参考：

  《特殊行业资质要求》

  ；
- 资质需保证真实，不得伪造或盗用其他产品信息，且始终保持资质在有效期内。

### **4. 知识产权**

开发者须确认提供的应用为原创或获得合法授权，不得在未经授权的情况下，使用他人的成果。应用应符合以下要求，如存在侵犯他人知识产权的情况，比亚迪有权下架违规应用，并拒绝应用发布和更新申请。

- 应用不得以误导用户的方式使用与其他开发者应用相同或相似如外观、名称、主题等。应用不得使用不当方式或在未经授权的情况下使用相同或相似商标，可能导致用户对相关商品的来源造成混淆；
- 开发者需获取许可授权，才能在应用内使用他人知识产权成果；
- 游戏类应用不得为有明确版权归属的破解版、汉化版；
- 应用及其内容不得侵犯他人在先权利，也不得以帮助、诱导等方式间接侵犯他人在先权利。

### **5. 付费服务**

开发者承诺提供的应用程序遵守《中华人民共和国消费者权益保护法》《中华人民共和国电子商务法》《网络交易监督管理办法》以及国家强制标准等相关规定和政策。

开发者保证其提供的应用遵循如下要求：

- 应用内含付费项，包括但不限于应用内购买项、自动续费服务等，开发者保证清晰明示产品功能权益及资费等内容，存在开通会员、收费等附加条件的进行显著提示。未经明示，不得在提供产品服务过程中擅自添加限制性条件，并以此为由终止用户正常使用的产品功能和服务，或降低服务体验。
- 采取自动续订、自动续费方式提供服务的，开发者保证在支付界面显著位置，明示自动续费服务协议（如“自动续费服务条款”等）及解除自动续费服务的说明和流程，并征得用户同意。不得默认勾选、强制捆绑开通。在自动续订、自动续费前5日以短信、消息推送等显著方式提醒用户，服务期间应提供便捷的随时退订方式和自动续订、自动续费取消途径。

### **6. 应用分发**

开发者承诺提供含应用分发下载功能的应用遵守《移动互联网应用程序信息服务管理规定》《中华人民共和国个人信息保护法》《网络安全法》《数据安全法》《App违法违规收集使用个人信息行为认定方法》《互联网信息服务管理办法》以及国家强制标准等相关规定和政策。

应用提供小程序分发功能的，还应保证对小程序可申请的信息和授权进行访问控制，涉及小程序通过框架型应用软件的开放接口获取个人信息或授权的，在用户授权前，框架型应用软件应保证小程序无法对相关数据或资源进行访问及控制。

### **7. 应用安装卸载**

开发者承诺提供的应用程序遵守《中华人民共和国消费者权益保护法》《中华人民共和国网络安全法》《网移动互联网应用程序信息服务管理规定》《App违法违规收集使用个人信息行为认定方法》《中华人民共和国反不正当竞争法》以及国家强制标准等相关规定和政策。

开发者保证其提供的应用遵循如下要求：

应用可以正常安装和卸载，不得以任何理由拒绝用户卸载应用，包括不得以空白名称、透明图标、后台隐藏等方式欺骗用户，阻挠用户进行真实有效的卸载操作。

### **8. 信息窗口弹窗**

开发者承诺提供的应用程序遵守《中华人民共和国广告法》《互联网弹窗信息推送服务管理规定》《中华人民共和国消费者权益保护法》《互联网信息服务管理办法》《中华人民共和国广告法》以及国家强制标准等相关规定和政策。

应用开屏或运行时，提供弹出信息窗口的，开发者承诺遵守如下要求：

- 开屏和弹窗信息窗口提供清晰有效的关闭按钮，保证用户可以便捷关闭。不得提供虚假、无效、标识不明显的关闭选项。
- 不得频繁弹窗干扰用户正常使用，或利用“全屏热力图”、高灵敏度“摇一摇”等易造成误触发的方式诱导用户操作。
- 行车过程中，不得弹出和行车场景下无关的、影响行车安全的信息弹窗或消息推送。
- 如应用内在展示界面存在互联网广告，应遵守《中华人民共和国广告法》等相关要求。

### **9. 应用内广告**

开发者承诺提供的应用程序遵守《中华人民共和国广告法》《互联网广告管理暂行办法》《中华人民共和国消费者权益保护法》《网络安全法》《互联网弹窗信息推送服务管理规定》以及国家强制标准等相关规定和政策。

应用提供互联网广告推送服务的，包括开机展示、待机展示、弹窗等形式，开发者承诺广告具有明确的关闭标志，确保一键关闭，不存在以下设置障碍的行为：

- 没有关闭标志或者计时结束才能关闭广告。
- 关闭标志虚假、不可清晰辨识或者难以定位等，为关闭广告设置障碍。
- 关闭广告须经两次以上点击。
- 在浏览同一页面、同一文档过程中，关闭后继续弹出广告，影响用户正常使用。
- 应用提供互联网广告的，开发者承诺广告具有可识别性，能够使消费者辨明其为广告。对于竞价排名的商品或者服务，开发者应当显著标明“广告”，与自然搜索结果明显区分。
- 未经用户同意、请求或者用户明确表示拒绝的，开发者承诺应用不得在车辆行驶过程中自启动或弹窗推送互联网广告。
- 应用向用户推荐下载应用的，开发者保证遵守如下要求：
- 应真实、准确、完整地明示开发运营者、产品功能、隐私政策、权限列表等必要信息，并同步提供明显的取消选项。不得通过“偷梁换柱”“移花接木”等方式欺骗误导用户下载应用。
- 开始下载前，应征得用户主动选择同意，不应在用户点击信息窗口任意位置即下载、安装、使用应用。
- 不得欺骗误导用户下载、安装、使用应用，包括但不限于在未明示下载应用情况下通过在信息窗口展示“是否立即开始游戏”、“领取红包”、“手机卡顿”、“耗电太快”、“内存已满”等信息诱导用户点击并下载安装。
- 用户暂停或取消应用下载、安装服务后，不得自动恢复下载、安装。
- 信息窗口中展示的应用信息应与实际下载、安装的应用信息相符。
