## **『九号』滑板车**

九号滑板车通过蓝牙协议接入“智慧物联APP”，用户通过车机大屏或者车内语音助手，实现滑板车电量和续航查询。车机大屏/语音查询功能：电量显示、故障报警、查询- 续航显示、查询- 状态播报（续航、电量）。

视频 1-1 滑板车使用场景

### **1. 车机大屏控制**

车机大屏上，滑板车相关的功能有：

- 电量显示

  ；
- 续航显示

  ；
- 故障报警；
