## **云云对接开发套件**

### **1. 云云接入示意图**

比亚迪为自有云的第三方企业开发者，提供加入比亚迪IoT云的方式，实现比亚迪车机远程查看和控制三方云授权的IoT设备，如车家互联——车控家。DiLink车机与比亚迪云平台通信，获取三方云家居设备列表、物模型、属性，信息、状态缓存，关联车机账号信息；云云接入支持车机大屏、车机语控、快捷指令。车机智慧物联App、智能语音，会展示和控制已获授权（OAuth2）的家居设备，如下图 1-1 云云对接示意图。

### **2. 云云接入协议**

开放平台向签署AIoT业务协议的企业用户开放《[比亚迪智能设备云云对接协议](#/researchTools/protocolDetail?id=278)》。用户前往【[管理中心-AIoT服务平台-开发协议](#/researchTools/developAgreement)】即可看到该云云接入协议。

### **3. 云云接入流程**

开放平台为云云接入提供了web端接入流程，以及测试环节。在完成企业资质认证并签署AIoT业务协议后，前往【[管理中心-AIoT服务平台-产品接入-产品管理](#/product/productList)】，选择三方云要接入比亚迪IoT云的产品类型，如图 3-1，分别创建不同的云接入产品，如冰箱、空调等，[创建产品](32-创建产品.html)时接入方式选择“云云对接”，然后前往[应用管理](#/product/appList)和[云对接配置](#/product/cloudDocking)，完成对应的应用配置和授权信息配置。

- 关联应用时需要选择【

#### **3.2 应用管理**

在[应用管理](#/product/appList)创建应用时，开发者填写三方云的移动应用或服务器应用的名称和包名，平台会自动生成App ID和App Secret。App ID和App Secret用于三方云向比亚迪IoT云推送设备信息的协议字段，具体可以参考协议《[比亚迪智能设备云云对接协议](#/researchTools/protocolDetail?id=278)》的2.3章节。如下图 3-3 创建应用的界面，图 3-4 创建完应用的详情界面。

平台类型：

- 如果您有对应的智能设备App，建议选择“移动应用”，应用名称填写智能设备App名称，应用包名填写智能设备App包名。
- 如果您没有对应的智能设备App，建议选择“服务器应用”，应用名称填写服务器名称，应用包名填写服务器主进程名。

#### **3.3 云对接配置**

[云对接配置](#/product/cloudDocking)包括4个步骤，如下图 3-5。其中在双方调试阶段，开发者需要配置“开发者OAuth(测试)”，里面包含一系列OAuth2相关授权信息；同理，节点“开发者OAuth(生产）”需配置正式环境的相关授权信息。可以参考协议《[比亚迪智能设备云云对接协议](#/researchTools/protocolDetail?id=278)》的1.2章节方案流程图。

上图“开发者OAuth(测试)”的相关参数说明，请见下表：

|  |  |
|---|---|
| 参数 | 说明 |
| 授权回调地址 | 比亚迪提供。用户在三方侧登录成功，企业开发者需根据该地址调用比亚迪接口，通知登录结果。 |
| 物模型通知地址 | 比亚迪提供。用户新绑定/移除设备，或者设备上线/离线，设备物模型值发生变化，企业开发者需要根据该地址推送至比亚迪侧。 |
| Client ID | 合作的企业开发者颁发给比亚迪侧的OAuth服务认证ID。 |
| Client Secret | 合作的企业开发者颁发给比亚迪侧的OAuth服务认证凭据。 |
| 授权地址 | 合作的企业开发者提供，用于给比亚迪授权的服务器域名地址。 |
| 设备地址 | 合作的企业开发者提供，允许设备远程访问和控制的服务器域名地址。 |
| 登录页面地址 | 合作的企业开发者提供给比亚迪，登录管控设备App的H5页面地址，用于车机端用户登录该三方企业账户进行设备授权。 |
