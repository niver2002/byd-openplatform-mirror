# 数据安全技术要求

> 来源：应用分发业务 / 应用分发审核管理规范 / 数据安全技术要求 · https://openplatform.byd.com/#/document/index?id=214

## **三方生态应用数据安全技术要求**

### **1. 范围 **

本标准适用于中国市场座舱三方生态应用数据安全检查，明确了三方应用数据安全评估及上架审核要求。

### **2. 定义**

#### **2.1 个人数据**

以电子或其他方式记录的与已识别或可识别的自然人有关的任何信息，如姓名、身份证号、联系方式等

#### **2.2 敏感个人数据**

需特殊保护的个人数据，包括生物特征信息（如指纹、面部识别）、医疗健康信息、金融账户信息、宗教信仰等，泄露可能导致重大风险。

#### **2.3 TLS**

传输层安全协议（Transport Layer Security），用于加密网络通信的行业标准协议。

#### **2.4 系统默认配置**

操作系统或应用预设的配置参数，如网络设置、默认应用（如浏览器、短信应用）等，修改需用户明确授权。

### **3. 三方生态应用数据安全检查要求**

数据安全上所有第三方应用（含集成SDK的应用）需通过数据安全检查，评估通过后方可上架；未通过者须提交数据安全声明并经审批通过后，方可发布上架。

#### **3.1 加密传输**

所有个人数据、敏感个人数据（如密码、生物特征）需通过 TLS 1.2 或更高版本等加密协议传输，禁止明文传输。

针对敏感个人数据、重要业务数据，应保证相关数据的完整性，避免传输过程被篡改。

#### **3.2 加密存储**

应用的敏感个人数据需加密存储，保证数据的机密性、安全性。加密算法可使用主流的安全加密算法进行数据安全存储。

#### **3.3 禁止恶意代码**

应用不得包含病毒、木马、可疑程序或其他威胁系统或数据安全的代码。

应用不得动态加载未经安全验证的第三方代码。

#### **3.4 禁止数据窃取**

应用不得暗中窃取用户数据（如账户信息、位置、通讯录等），禁止通过键盘输入等方式监控用户行为。

#### **3.5 日志安全**

应用的日志在出车前，如涉及敏感个人数据的日志需脱敏后存储。

#### **3.6 数据安全应急响应**

第三方应用如涉及比亚迪汽车用户数据处理活动的，应提供适用的应急响应预案或规范进行备案。

#### **3.7 数据跨境检测**

针对第三方应用，如涉及数据收集活动且存在数据跨境的情况，应禁止此类应用上架。
