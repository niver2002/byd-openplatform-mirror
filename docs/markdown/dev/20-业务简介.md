# 业务简介

## **业务简介**

比亚迪生态开放平台的**应用分发业务**，旨在为开发者提供全面、规范、高效的三方应用接入解决方案。平台致力于构建统一、标准化的应用接入流程与技术规范，配套完善且功能强大的API接口，全面支持开发者实现应用的快速集成与稳定运行。通过持续优化技术能力与服务能力，比亚迪生态开放平台助力开发者提升开发效率、缩短上线周期，推动创新成果快速落地，携手打造开放、协同、共赢的智能生态体系，共同引领未来智能出行与数字化服务的发展新方向。

### **1.您可以得到什么？**

接入比亚迪生态开放平台应用分发业务的应用，将能够充分**借助比亚迪车机应用市场所拥有的庞大用户基础与高活跃度的用户群体，实现应用的高效触达与快速推广。**开发者可依托开放平台提供的标准化API接口，灵活调用车机系统核心功能，进行应用的功能扩展与深度集成，从而构建更加智能化、场景化、个性化的车载应用体验。通过以用户为中心的设计理念，打造覆盖出行、娱乐、服务等多维度的生态应用系统，助力开发者共同构建开放、智能、可持续发展的车联网生态系统。

### **2.您如何接入本业务？**

作为开发者，如果您希望将您的应用推广至比亚迪车主用户群体，诚邀您即刻加入比亚迪生态开放平台应用分发计划。通过开放平台提供的全方位技术支持与高效的应用接入流程，助力您的应用快速触达海量用户，实现价值最大化。可依据开放平台应用分发业务接入指南迅速接入。

#### **2.1 注册账号**

您需要[注册](#/login?type=sms)比亚迪开发者账户。

#### **2.2 成为比亚迪开发者**

应用分发业务面向个人和企业开发者，如果您未通过个人认证或企业认证，请您提交[个人或企业开发者认证资料](#/login?redirect=/developer/type)，并通过平台审核，详情可参考[开发者注册认证](101-开发者注册认证.html)。

#### **2.3 签署业务协议**

您需要完成[《应用分发业务协议》](147-应用分发业务协议.html)、[《合规承诺》](148-应用分发业务合规承诺.html)和附件协议（如有）的签署，获取应用分发业务开发者权限。

#### **2.4 应用注册**

您需要完成应用注册信息的填写，包括：**软件包类型、应用名称、应用类型。**

#### **2.5 应用开发与自测**

根据应用开发需要，如涉及空调控制、行驶数据获取、车速显示等车辆相关功能，您可以从比亚迪生态开放平台获取[标准API接口](#/developTools/apiLib)，进行开发和自测，自测成功后，测试报告需在版本信息完善阶段上传至比亚迪生态开放平台。

#### **2.6 版本信息完善与应用提交**

您需要按照平台的要求填写相关的**应用信息、推广信息、资质信息、自检信息、联系人信息**，以便后续平台对应用进行审核，您在完成版本信息完善要求的所有信息填写、资质材料上传后，即可进行应用提交。

#### **2.7 应用审核**

比亚迪为开发者提供应用分发业务的测试、验收的服务，对应用进行全面检查、测试和评估，以确定应用是否符合预定的标准、质量要求和用户期望以及国家要求的法律法规、强制标准等相关规定和政策。主要包括**”功能测试“、“合规测试“、“用户体验测试”**三部分，只有通过应用测试验收的所有环节，应用才可以发布和上架。

#### **2.8 应用发布**

**您通过比亚迪的应用审核后，由比亚迪负责上架您的应用。**
