# 获奖通知说明

> 来源：主题商店业务 / 比亚迪智能座舱设计大赛 / 获奖通知说明 · https://openplatform.byd.com/#/document/index?id=58

## **2026比亚迪智能座舱设计大赛获奖通知**

1、获奖通知将在结果公示后7个工作日内，通过短信或官网站内信发送至获奖作者或监护人，请确保报名时提供的联系方式真实有效，避免错过通知。

2、若获奖作者或监护人在通知限定时间内未回应（如未提交源文件、未签署协议等），将视为自动放弃奖项，主办方将从其他入围者中择优选取替补获奖人员。

3、本次大赛所有奖金均为税前金额（以人民币结算）。奖金具体发放时间将根据协议签署进度确定，预计在最终公示后3个月内完成发放，请获奖作者耐心等待，相关进展将通过短信同步。
