1.3 开发者：指在本平台完成在线注册并通过开发者认证使用开放平台相关服务和/或向最终用户提供开发者产品的的自然人、法人或其他组织。本平台下不同业务板块的开发者类型可能存在差异，如“比亚迪AIoT业务”仅面向企业开发者；“比亚迪应用分发业务”，面向个人/企业开发者；“比亚迪主题商店业务”，面向个人/企业开发者。

1.4 产品：指由开发者开发、在本平台创建并上传的的IoT设备、应用、软件、功能、内容、数字资料及其它产品和服务。

1.5 产品信息：指开发者通过开放平台或其他方式提供给比亚迪的产品相关信息，包括但不限于产品内容、产品描述及任何产品营销相关资料等。

1.6 关联公司：是指被一方控制、或控制该方、或与该方共同控制同一家公司、或与该方共同受控于同一家公司的法律实体。而在此“控制”一词的意思是：通过协议、股权或其他方式，直接或间接地拥有权利（所有权或有资格选举董事的股权或参股权）控制或影响一个公司或实体的经营、管理。

1.7 比亚迪渠道：是指由我们及关联公司具有运营权利的网站、移动应用程序、快应用、应用市场等各类在世界范围内发布的互联网产品、由我们及关联公司生产和销售的终端设备产品、并为最终用户提供任何服务的平台。我们借助比亚迪渠道对您的产品进行分发、推广，您理解并同意我们有权根据业务需求自行调整比亚迪渠道的具体产品及服务内容。

1.9 “个人数据”：也称作“个人信息”，指以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。
