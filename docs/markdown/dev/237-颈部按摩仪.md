## **『倍轻松』颈部按摩仪**

### **1. 车机联动功能**

倍轻松颈部按摩仪通过蓝牙协议接入“智慧物联APP”，用户通过车机大屏或者车内语音助手，实现对颈部按摩仪传统艾灸、艾灸碳、光疗、大师模式、放松模式、开肩模式等功能。

![车机大屏操控.jpg](../assets/fba83a68cd714bba92873e5227e21154-0a4d5b.jpg)

图 1-1 颈部按摩仪车机联动

#### **1.1 车机大屏控制**

- 模式支持“开肩”、“混合”、“热灸”三种模式切换；
- 手法替换支持“混合”、“拔筋”、“活力”、“硬核”；
- 按压支持“低挡”、“中挡”、“高挡”三挡调节；
- 热敷支持“关闭”、“低挡”、“高挡”三档调节；
- 定时设置支持多种时间段；

#### **1.2 车机语音功能**

车机智能语音实现了车机大屏控制颈部按摩仪的全部功能。方便用户解放双手，畅享按摩。

### **2. 手机控制功能**

颈部按摩仪离开车机的使用场景中，手机也可控制按摩仪的功能。从手机端比亚迪App的"我的->智慧物联"，添加颈部按摩仪，进入按摩仪的控制界面，该界面可显示并控制颈部按摩仪剩余电量、热敷模块状态、按压调节和剩余时间、当前模式等。
