**优秀作品示例**

精选平台上线的优质车机主题，供开发者参考学习。

【作者】：Honey

【主题名称】:   玫瑰星球

【主题简介】：玫瑰坠入星河，你落在我心上

【交互方式】：随机播放，含昼夜模式。双击切换不同星球状态

【作者】：Rui睿睿

【主题名称】:   原点

【主题简介】：被遗忘在宇宙尽头的角落，一束光落在肩上，独自前行，也是探索的起点

【交互方式】：顺序播放+过渡动画，双击切换多种状态

【作者】：沙丁酱

【主题名称】:   云栖

【主题简介】：松松软软的泡沫云朵，堆叠在蓝天的画布上。昼夜两种色彩，双击切换萌趣状态。放松，从看到云朵的那刻开始

【交互方式】：顺序播放+过渡动画，含昼夜模式。双击切换萌趣状态

【作者】：YOMeeDoll有咪兜

【主题名称】:   小企鹅兜兜-宠鹅海岛

【主题简介】：小企鹅兜兜躺平泡汤、远航垂钓、沉浸式海岛下午茶，双击解锁兜兜的松弛假日吧。

【交互方式】：主场景串联，双击企鹅岛上5处带有小企鹅兜兜的画面区域，即可解锁对应动态场景，再次双击即可返回主岛

【作者】：YOMeeDoll有咪兜

【主题名称】:   小企鹅兜兜-露营日记

【主题简介】：和企鹅兜兜一起露营，让生活慢下来。双击屏幕，换种野法

【交互方式】：主场景串联，含昼夜模式。双击左中右热区切换不同场景

【作者】：夏语猫

【主题名称】:   疯癫杀马特

【主题简介】：视觉冲击力极强的灵魂爆炸头小猫，五种疯癫状态随机切换，专治各种无聊。双击，解锁下一个疯癫瞬间

【交互方式】：随机播放+过渡动画，双击切换不同疯癫状态
