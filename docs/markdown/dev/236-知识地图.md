# 知识地图

> 来源：知识地图 · https://openplatform.byd.com/#/document/index?id=236

[比亚迪生态开放平台](#/dashboard/analysis)以智能座舱与车生活场景为核心，深度融合**AIoT技术、应用分发、主题共创**等生态，面向**智能硬件开发者**、**车机应用开发者**、**主题设计开发者**，提供覆盖开发赋能、测试验证、营销运营的全链路标准化技术解决方案与生态资源支持。平台致力于构建“以车为核心 链接一切”深度协同的开放生态体系，通过技术标准化与生态协同化，实现硬件、软件与服务的无缝联动，为车端用户打造场景化、个性化的智慧出行体验。

欢迎广大开发者[加入](#/dashboard/analysis)比亚迪智慧生态的大家庭。
