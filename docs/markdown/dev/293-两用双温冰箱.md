# 两用双温冰箱

> 来源：AIoT业务 / 合作案例 / 直连接入 / 两用双温冰箱 · https://openplatform.byd.com/#/document/index?id=293

## **『美的』两用双温冰箱**

![image.png](../assets/0472d3a2aee24891ad01ebebf31faa6c-06b22b.png)

图 1-1 美的两用双温冰箱

美的两用双温冰箱，通过蓝牙协议接入“智慧物联APP”，用户通过车机大屏，操控冰箱冷冻启停、调温、模式切换功能。同时为用户提供各类场景自动化功能，用户在“智慧物联APP”场景中配置冰箱联动。

![image.png](../assets/5f96352b4bed4ca4984ac1116e2a4f42-a55753.png)

图 1-2 车机操控冰箱

### **1.  车机大屏控制**

车机大屏控制冰箱的功能有：

- 冰箱

  冷冻启停

  ；
- 温度显示、调节（

  -20℃～20℃

  ）；
- 强劲制冷/节能制冷模式切换；
- 温标切换；
- 电源低压保护选择；

![image.png](../assets/cbac0a1064844f5e98befa13bb9458dd-b2ff4f.png)

图 1-3 车机大屏操控

### **2.  场景自动化功能**

用户在车机端“智慧物联APP”场景中，可以根据需要配置冰箱联动。
