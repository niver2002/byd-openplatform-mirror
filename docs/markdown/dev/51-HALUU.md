## **HALUU**

HALUU是腾讯音乐旗下的潮流音乐IP，一只拥有奇思妙想的捣蛋鬼，也是爱听音乐的小精灵。

2026年，HALUU正式入驻比亚迪生态开放平台，双方联合共创车机主题：白天的HALUU摇摇晃晃陪你听歌；夜晚则静下来陪你发呆，让车机从冰冷的屏幕变成有温度、有呼吸感的陪伴者。除了主题产品，双方还在行业内首次推出**“****盲盒+车机主题****”**组合商品，首批库存上线后**7日内售罄**，该组合商品不仅通过手机端网联商城线上销售，更已进入多家**线下门店试点展销**，实现线上线下联动，将主题内容与实体消费场景打通。
