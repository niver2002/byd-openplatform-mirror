# 应用审核Checklist

> 来源：应用分发业务 / 应用分发审核管理规范 / 应用审核Checklist · https://openplatform.byd.com/#/document/index?id=359

## **应用审核Checklist**

应用发布前，请务必仔细研读[应用市场审核指南](24-应用市场审核指南.html)，充分了解比亚迪应用市场上架审核的相关规则与要求，并提前备齐发布所需文件及资源，确保审核流程顺利推进。

为协助开发者做好应用上架前的准备工作，在提交审核前，请参照本清单所列事项完成自查，提前排查并整改常见问题。请确认全部检查项均已落实后，再行提交应用上架审核，审核结果以最终意见为准。

### **1. 适用范围**

个人开发者、企业开发者

### **2. 开发前**

|  |  |  |  |
|---|---|---|---|
| 阶段 | 模块 | 检查项 | 修改建议 |
| 开发前 | 应用名称 | 应用名称是否为泛化词汇，例如「免费天气」等 | 请规范应用名称，避免使用电话、邮件、日历等广义归纳类、缺乏识别性的通用词汇进行命名，并确保软件著作权登记证书所载软件名称与所提交的应用名称保持一致。 |
| 应用名称及图标 | 应用名称及图标是否与其他应用存在相同或近似情形，是否使用系统默认图标 | 1. 请提供应用名称及图标的权属证明文件，或对应用名称及图标进行修改调整；2. 代码开发阶段，应统一替换软件包内的图标。 |  |
| 应用功能 | 应用市场内是否已存在较多功能同质化的应用 | 建议审慎评估赛道竞争格局，避免在同类应用已高度饱和的品类中进行同质化开发。 |  |
| 应用备案 | 是否符合监管部门关于移动互联网应用程序备案工作的相关要求 | 请及时完成应用备案工作，确保备案信息中填报的主体信息、应用名称、应用包名与在架应用信息保持一致，并保证备案号处于有效状态。 |  |
| 特殊行业资质 | 应用内容是否涉及特殊行业内容类型 | 请对照内容类型核查清单，参照资质要求准备相应的资质证明文件。详见： 特殊行业资质要求 。 |  |

### **3. 开发中**

|  |  |  |  |
|---|---|---|---|
| 阶段 | 模块 | 检查项 | 修改建议 |
| 开发中 | 功能开发 | 应用功能体验是否完整连贯，是否具备实用价值并能够为用户提供实质性的功能或服务 | 请确保应用能够为用户提供完整、稳定、流畅且具有吸引力的功能体验。若该应用已发布其他端版本，车机端版本的功能质量与完善程度应不低于其他端版本，保障用户跨端体验的一致性。 |
| 应用自测 | 应用是否存在崩溃、功能异常等质量问题 | 为保障用户体验，软件包提交前应完成全面自检，及早发现并修复应用质量及体验问题。请参照 自测报告 相关内容逐项开展测试。 |  |
| 隐私合规 | 是否通过显著方式提示用户查阅隐私政策 | 应用首次启动时，应通过弹窗形式展示隐私政策，或在注册、登录等界面以显著方式呈现隐私政策，提示用户予以查阅。 |  |
| 隐私合规 | 是否存在在用户同意隐私政策前即收集个人信息的情形 | 请自查应用及所集成的第三方SDK，确保仅在用户同意隐私政策后，方可收集用户个人信息。个人信息的收集及权限申请均应在用户同意隐私政策之后进行。 |  |

### **4. 上架提审**

|  |  |  |  |
|---|---|---|---|
| 阶段 | 模块 | 检查项 | 修改建议 |
| 上架提审 | 软件包管理 | 软件包是否为正式发布版本 | 所提交的应用应为已完成自测的正式版本。 |
| 应用分屏情况 | 应用所支持的分屏模式 | 请选择应用支持的分屏模式，例如：5/5分屏、3/7分屏、不支持分屏、其他等。 |  |
| 应用适配分辨率 | 应用适配的分辨率规格 | 请选择应用适配的分辨率规格，例如：1920×1080、1728×1888、1920×720等。详见： 屏幕信息说明 。 |  |
| 应用适配屏幕 | 应用适配的屏幕显示类型 | 请选择应用支持的屏幕类型，例如：横屏、竖屏、通用（即旋转屏，可同时支持横屏与竖屏）。 |  |
| 应用分类标签 | 应用分类是否与实际功能及用途相符 | 请选择与应用实际功能及用途相符的分类。 |  |
| 应用接口 | 应用是否调用车机系统接口 | 应用提交前，请参照 接口清单 如实填报所调用的接口；未按要求填报的，审核可能予以驳回。 |  |
| 上架自检 | 是否提前检测应用在功耗、性能、兼容性、稳定性、用户体验及隐私合规等方面存在的问题 | 应用提交测试前，请参照 自测报告 完成各项测试，提前排查并整改上架环节可能存在的问题，以提升审核通过率、缩短上架周期。 |  |
| 可本地化基础信息 | 应用名称及图标是否与安装后显示一致 | 请确保所提交的应用名称及图标与应用安装后在终端显示的名称及图标保持一致。 |  |
| 应用审核信息 | 测试账号信息填报是否准确完整 | 若应用需登录后方可使用，请在提审页面的「测试账号」栏目中提供测试账号。请确保该测试账号可正常使用全部功能，不存在权限、角色、会员、付费等限制，以保障审核人员能够完成登录、浏览、操作、退出的全流程测试。 |  |
| 可本地化基础信息 | 应用简介、描述及预览图是否与应用实际情况相符 | 1. 请提交与应用实际功能内容相符的应用信息，包括应用图标、应用简介、应用描述、版本更新说明及应用预览图，避免误导用户。2. 请删除「国家级、最高级、最佳」等不符合《广告法》规定的相关表述。3. 请删除「test、demo、beta」等表明应用为测试版本或测试数据的词汇。详见： 应用市场审核指南 。 |  |
| 备案信息 | 是否已完成备案 | 请及时完成应用备案工作，确保备案信息中填报的主体信息、应用名称、应用包名与在架应用信息保持一致，并保证备案号处于有效状态。 |  |
| 备案信息 | 备案信息填报是否准确完整 | 若应用备案信息中的应用包名、应用名称、主体信息与在架信息不一致，可能导致备案校验不通过。请注意，填写「主体证件号」时，应注意区分「数字5」与「字母S」、「数字1」与「字母I」、「数字0」与「字母O」。 |  |
| 版权信息 | 应用内容是否涉及特殊行业内容类型 | 请参照 特殊行业资质要求 上传相应的资质证明文件。 |  |
| 资质信息 | 应用软件是否授权上架 | 请按照 应用软件授权书 模板签署后上传。 |  |
| 资质信息 | 隐私政策链接是否可正常访问 | 请确保隐私政策链接可正常访问 |  |
| 资质信息 | 用户协议链接是否可正常访问 | 请确保用户协议链接可正常访问 |  |
| 自检信息 | 竞品分析报告内容是否完整 | 请按照 竞品分析报告 模板完成编制，并上传。 |  |
| 自检信息 | 准入标准审核表是否填写齐全 | 请按照 准入标准审核表 模板填写完毕，并上传。 |  |
