# 保证金管理规则

> 来源：营销渠道 / 规则中心 / 保证金管理规则 · https://openplatform.byd.com/#/document/index?id=226

##### **保证金管理规则**

###### **一、概述**

1. 为促进比亚迪生态开放平台引入的开发者能够更好地服务消费者，特制订本规则，旨在明确保证金的存缴、补缴、划扣及退回等事宜。

2. 本规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。

###### **二、内容**

2.1 保证金，是指商家向比亚迪商城缴存，用以保证平台规则和协议的履行以及担保商家产品质量，担保对用户保障服务承诺的款项。

2.2 保证金存缴：商家应根据经营的类目，在商品上架前缴纳保证金。若商家涉及跨类型经营，则需按最高金额的类目缴纳。

|  |  |  |
|---|---|---|
| 公司规模 | 经营类目 | 保证金金额（元） |
| 0人<公司员工<20人以及个体工商户 | 软件、会员等无形产品 | 1000 |
| 硬件等有形产品 | 5000 |  |
| 20人≤公司员工＜1000人 | 软件、会员等无形产品 | 3000 |
| 硬件等有形产品 | 20000 |  |
| 1000人≤公司员工 | 软件、会员等无形产品 | 5000 |
| 硬件等有形产品 | 50000 |  |

2.3 保证金划扣

2.3.1 若商家在经营期间发生交易争议、违反协议、违规、发生重大负面舆情或被任何第三方发起投诉、举报、索赔、诉讼或仲裁等，比亚迪商城有权根据相关规则及协议从商家已缴付的保证金中扣除有关的款项，用于退款、赔付消费者、赔偿平台损失、支付违约金或其他应由商家承担的款项或费用。

2.3.2 当商家保证金不足以支付前述款项时，当商家的保证金不足以赔付消费者及其他权利人时，商家应自行支付额外的赔付金额，比亚迪商城没有义务使用自有资金向消费者或任何权利人支付任何款项。

2.4 保证金补缴

2.4.1 当商家的保证金余额低于商家保证金缴存标准时，商家应在收到比亚迪商城发出的续费通知之日起的7个工作日内及时补缴至应缴额。否则比亚迪商城有权同时采取以下一项或多项措施，直至保证金补足：

(1) 冻结商家未结算货款，或从商家未结算货款中划扣应补缴额；

(2) 下架部分或全部商品；

(3）追究商家的违约责任。

2.5 保证金退回：双方合作终止时，商家可申请保证金退还，比亚迪商城将予以审核。审核内容包括但不限于所有商品质保期届满、所有争议及索赔处理完毕等。审核通过的，比亚迪商城将依据协议及相关规则等扣除应扣除的部分后，比亚迪商城将保证金余额退还至商家账户。

2.6 保证金调整：比亚迪商城有权根据市场环境、业务发展需要、商家的经营类目变化以及商家信用状况、履约表现等因素，对商家应缴纳的保证金金额进行调整。对于调整前后的保证金缴存额，将在规定期限内进行多退（比亚迪商城将差额退回至商家指定的账户）少补（商家应在通知规定的期限内补足差额）。

2.7 其他

2.7.1 对于商家所缴存的保证金，比亚迪商城不需向商家支付任何利息。

2.7.2 保证金的缴存、划扣、补缴、退回等过程中所发生的银行收费等第三方费用，由商家承担，比亚迪商城有权从保证金余额中扣除。

2.7.3 对于保证金的缴存、划扣、补缴、调整，比亚迪商城将通过平台官方公告、站内信、电子邮件等一种或多种方式通知商家。

###### **三、附则**

3.1 规则变更：比亚迪商城有权根据业务需要或法律法规变化随时调整本规则。调整后的规则通过比亚迪生态开放平台向商家公示后生效。如商家不同意变更，可书面提出异议并停止使用相关服务；若商家在变更生效后继续使用服务，即视为接受变更后的规则。

3.2 生效时间：本规则于2026年1月1日首次发布，自2026年1月1日起正式生效。
