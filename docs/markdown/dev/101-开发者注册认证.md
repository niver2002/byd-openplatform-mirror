# 开发者注册认证

> 来源：开发者注册认证 · https://openplatform.byd.com/#/document/index?id=101

## **开发者注册认证**

### **1. 开发者认证流程概览**

1、开放平台账号是比亚迪生态开放平台的登录凭证，认证开发者身份前，需先注册开放平台账号；

2、请根据实际情况选择开发者认证类型：企业开发者、个人开发者；

3、企业开发者需填写企业信息、法人身份证号、法人身份证照片等信息进行人工审核。人工审核时间为1~3个工作日。

4、个人开发者需填写姓名、身份证照片、身份证件号、邮箱地址、通讯地址等信息进行人工审核。人工审核时间为1~3个工作日。

### **2. 认证相关名词解释**

#### **2.1开发者账号定义**

**开发者账号**用于在开放平台发布您的产品，由**开放平台账号**和**企业开发者认证**/**个人开发者认证**组成。

**开放平台账号**： 作为比亚迪生态开放平台的登录凭证，由开放平台账号提供登录服务；

**开发者认证**： 作为开发者的身份信息认证，由比亚迪生态开放平台提供开发者服务；

**开发者账号**： 开放平台账号+开发者认证=开发者账号。

#### **2.2 开发者认证权益**

平台目前开放范围包含AIoT业务和应用分发业务，开发者认证后的权益范围如下：

|  |  |  |  |
|---|---|---|---|
| 业务类型 | 是否开放 | 企业开发者 | 个人开发者 |
| AIoT | 是 | ✔ | ✘ |
| 应用分发 | 是 | ✔ | ✔ |
| 主题商店 | 待开放 | ✔ | ✔ |

### **3. 注册开放平台账号**

比亚迪生态开放平台使用开放平台账号作为登录凭证，因此，在进行开发者认证之前，您需完成注册开放平台账号。

#### **3.1 注册开放平台账号**

登录 [比亚迪生态开放平台首页](#/dashboard/analysis)，点击导航栏最右侧注册按钮，按照页面提示操作，或[点击这里](#/login)注册开放平台账号。

### **5. 常见问题与注意事项**

#### **5.1 企业认证需要先完成个人实名认证？**

A：是的。因为企业认证需要提交企业的详细信息和资料，进行企业认证的开发者也是该企业在生态开放平台的创建者，当企业认证成功，该创建者即默认成为该企业在生态开放平台的超级管理员，对该企业有最高的操作权限，可以添加成员到该企业，并分配其他成员角色（包括管理员和普通成员），所以需要先完成企业创建者的个人实名认证。

#### **5.2 企业管理员如何为添加成员？**

A：企业管理员登录开放平台后，进入【[个人中心-企业信息](#/personal/enterpriseInfo)】，在对应的企业所在行，点击“添加成员”按钮，即可为该企业添加成员，并为该成员分配角色和添加备注名称，如下图5-1，关于企业开发者角色可参考本文档 4.1.1 章节。

注意：被添加的企业成员需要先在比亚迪生态开放平台完成个人实名认证，个人认证参考4.2章节。企业成员被企业管理员添加成功后，登录开放平台后需要先切换身份为企业身份，参考4.1.6章节。

![image.png](../assets/099a4fb892b54c14ae6e9013d3d4ff78-bdc228.png)

图 5-1 为企业添加成员

#### **5.3 企业身份和个人身份有什么不同？**

A：本平台支持个人身份和企业身份切换。

- 如切换到个人身份，

  后续产品提交、版本更新、收益结算等所有操作

  ，

  都将自动归属到个人；
- 如切换到企业身份，

  后续产品提交、版本更新、收益结算等所有操作

  ，

  都将自动归属到企业。本平台入驻的企业支持多成员管理企业事项，如产品提交等。企业成员角色分为：超级管理员、管理员、普通成员。

  关于企业开发者角色可参考本文档 4.1.1 章节。

#### **5.4 已经通过企业认证是否自动切换为企业身份？**

A：不会。平台会自动记忆您上次登录使用的身份（个人 / xxx企业）。下次进入时，默认沿用上次的身份状态，无需重复切换。 当收到短信或站内信通知“通过了企业认证”，登录平台并切换为对应的企业身份后，后续操作才能归属为该企业行为，身份切换路径【[个人中心-个人资料](#/personal/personalInfo)】，具体可参考本文档 4.1.6 章节。
