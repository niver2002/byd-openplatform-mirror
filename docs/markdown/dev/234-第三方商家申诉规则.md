# 第三方商家申诉规则

> 来源：营销渠道 / 规则中心 / 第三方商家申诉规则 · https://openplatform.byd.com/#/document/index?id=234

##### **第三方商家申诉规则**

###### ** 一、概述**

###### **1.1 适用对象**

本规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。

###### **1.2 适用情景**

本规则适用于第三方商家被比亚迪商城判定违规后发起申诉的情景。

###### **二、申诉流程**

2.1 第三方商家在被比亚迪商城判定为违规后，如存在异议，可在规定申诉时效内通过联系邮件向比亚迪商城发起申诉，并按要求提交相关证明材料。具体申诉时效以第三章《申诉实施细则》约定为准。如需补充其他材料，以比亚迪商城的另行通知为准。

2.2 比亚迪商城在收到第三方商家申诉后，将审核商家提交的申诉材料，并在合理期限内反馈处理结果。若申诉成功，则比亚迪商城对应违规处理不予执行或中止执行。商家发起申诉或申诉期间不影响平台之前判定商家违规决定的效力。

2.3 为保障申诉有效性并提高申诉成功率，第三方商家在发起违规申诉时，须按比亚迪商城要求提供完整、真实、有效的证明材料，包括但不限于：聊天记录、截图、链接、照片、录音、快递单据等。

###### **三、申诉实施细则**

3.1. 申诉场景说明：第三方商家在经营过程中如因违反平台规则受到平台处罚，可在收到违规通知后的7个自然日内通过联系邮件向比亚迪商城发起违规申诉。

3.2 申诉机会：针对同一事项，商家最多只有一次发起申诉机会。

3.3 申诉处理时效：一般为30个自然日（如商家承诺进行改进，申诉处理周期可能相应顺延）。

|  |  |  |
|---|---|---|
| 违规类型 | 情况说明 | 申诉材料参考 |
| 出售假冒商品 | 商家出售假冒、盗版商品的行为。 | 需提供完整、可追溯的进货凭证链路，包括但不限于购物发票、电子订单、采购合同、厂家订/出货单等。 |
| 出售质量不合格商品 | 商家出售的商品品质不符合国家标准、行业标准、平台标准或商家自身承诺的标准。 | 提供具备CMA/CNAS资质的检测机构出具的质量检测合格报告，报告出具日期距申诉日不超过1年。 |
| 发布违禁信息 | 商家发布涉黄、涉暴、涉毒或其他违反公序良俗、国家法律法规的商品或信息。 | 提供商品详细信息、营销活动信息等证明商品无违规内容的材料。 |
| 虚假宣传 | 商家在商品或服务的信息发布中，对商品或服务的特征、产地、价格、质量、成分、性能、用途、生产者、有效期限等关键信息，作出与客观事实不符的描述，导致消费者被误解或产生误解。 | 提供商品详细信息（可包括质量检测报告、商品实拍图等）、营销活动信息等证明商品无违规内容的材料。 |
| 知识产权侵权 | 商家所使用的宣传内容、商品信息等，侵犯他人商标权、专利权、著作权等合法权益。 | 1. 提供权利证明文件（如商标注册证或商标授权书、作品创作过程证据）2. 提供相似度对比分析。 |
| 虚假交易 | 商家通过虚构交易、虚构评价等方式，获取虚假的商品销量、评价、店铺评分等不当利益。 | 1. 交易凭证：例如与订单对应的发票、合同、往来沟通记录等可证实真实交易背景的文件。2. 物流凭证：提供与订单运单号相符的物流或快递详情截图，截图内容需完整、清晰可辨。 |
| 提供虚假证照 | 商家在入驻或经营过程中，提供虚假的营业执照、行政许可等资质文件。 | 提供官方验证平台中资质文件的截图（如营业执照、行政许可文件）等。 |
| 泄露他人信息 | 泄露他人信息：商家未经允许发布、泄露、传播消费者或其他第三方的个人信息，侵犯他人隐私权或产生个人数据泄露。 | 提供访问日志与操作记录，或其他可以辅助证明的材料。 |
| 恶意骚扰 | 恶意骚扰：商家通过电话、短信、邮件等方式，对消费者或其他第三方实施侮辱、恐吓、诋毁等行为，妨害他人合法权益。 | 提供完整的交流沟通记录截图或其他可以辅助证明的材料。 |
| 延迟发货/拒绝发货 | 延迟发货：除特殊商品或约定外，商家在消费者付款后未在规定时间内完成发货。拒绝发货：订单成立后，商家在无正当理由的情况下拒绝向消费者发货。 | 1. 双方协商延迟发货：提供您与买家关于延迟发货的聊天记录；或买家在发货超时前已申请退款的记录。2. 不可抗力因素导致无法按时发货：提供快递网点证明或政府通知等任一有效凭证。 |
| 未按标准提供客服服务 | 商家未在比亚迪商城规定时限内响应或处理客户咨询与投诉，或服务过程违反法律法规及平台规则，引发用户投诉。 | 提供非商家责任证明。 |

###### **四、附则**

4.1 规则变更：比亚迪商城有权根据业务需要或法律法规变化随时调整本规则。调整后的规则通过比亚迪生态开放平台向商家公示后生效。如商家不同意变更，可书面提出异议并停止使用相关服务；若商家在变更生效后继续使用服务，即视为接受变更后的规则。

4.2 生效时间：本规则于2026年1月1日首次发布，自2026年1月1日起正式生效。
