## **联系我们**

为保障您的信息权益，比亚迪严格遵守《中华人民共和国个人信息保护法》及相关法律法规，始终遵照我们的隐私政策来收集和使用您的信息，您可查阅完整的[《比亚迪生态开放平台隐私政策》](5-隐私政策.html)，了解数据收集范围、使用规范及安全保障措施。我们承诺未经授权不向第三方披露用户信息，并为您的隐私安全护航。

欢迎您通过以下渠道获取技术支持、商务合作或反馈建议，我们全程助力共同打造极致的智能出行体验之旅！

### **1. 提交工单**

[工单管理](#/personal/work-order)用于处理比亚迪生态开放平台业务相关的问题。若文档中心的帮助文档无法提供有效的解决方案，且您没有和比亚迪建立专属的沟通渠道，可通过【个人中心-工单管理】提交工单，系统会根据一级标签、二级标签分配到相应支持团队处理。工单处理遵循单次受理原则，为确保高效解决问题，请您在提交工单时务必一次性完整描述问题背景、具体需求及期望结果，以便我们一次性提供准确解决方案。对于复杂事项，建议分别提交工单。比亚迪支持团队将在您提交工单后 1-3个工作日内回复。如您已收到解决方案，可手动关闭工单并为我们评分，助力我们持续优化服务；为保持服务效率，未关闭的工单将在 5个自然日后自动关闭。
