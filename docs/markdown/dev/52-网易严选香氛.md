## **网易严选香氛**

网易严选是国内知名生活方式品牌，入驻比亚迪生态开放平台后，双方联合推出“四季流年”车机**主题与车载除味香氛组合商品**。用户双击车机屏幕，即可切换四季风光，搭配车载香氛，实现**视觉与嗅觉的双重感官联动**，营造沉浸式座舱体验。首月上线，该组合商品销量即跃升至平台**车载香氛品类TOP1**。此次跨品类合作，成功拓宽了主题内容的消费场景。
