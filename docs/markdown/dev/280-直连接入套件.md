## **直连接入开发套件**

直连接入，即短距技术协议接入，您可以通过开放平台短距技术协议和工具，实现近场 IoT 设备直连接入比亚迪车智能座舱。短距技术包括 BLE 协议和 Wi-Fi 协议，对应的测试工具有：短距 IoT 协议测试助手。短距协议对接的开发方式，可以让您不用额外增加硬件成本，即可迅速接入比亚迪智慧生态。

### **1. BLE协议和工具**

#### **1.1 BLE GATT协议**

比亚迪车智能座舱作为主设备，所有接入比亚迪车智能座舱的 IoT 设备做为从设备，采用 BLE GATT 协议智能座舱能快速发现并与 IoT 设备建立连接，IoT 设备通过广播表明自己的存在，等待被连接。IoT 设备的广播包中包含设备的相关信息，能够及时被座舱识别和连接。

主从设备均需兼容此协议规定的通信协议及数据格式，包括内容如下：

**（1）BLE GATT协议定义的广播，扫描，建立连接，MTU 协商，服务和特征发现过程**；

**（2）支持添加 BLE 协议标准定义的标准服务和自定义的Service服务及特征，用于实现智能座舱对IoT设备的控制、联动、OTA升级触发和数据传输**。

- BLE SIG 定义的标准服务

建议优先支持 BLE SIG 定义的标准服务，包含Device Information Service，Battery Service，Current Time Service，Device Time Service，如下图 1-1。

- 自定义的基础服务

若上述BLE SIG定义的标准服务IoT设备不能支持，需要添加自定义的AutoIot Device Information Service，AutoIot Battery Service，AutoIot Current Time Service，AutoIot Device Time Service，如下图 1-1。

- 自定义抽象服务

通过对设备服务抽象化，设备可基于所需功能需求，选择和搭配比亚迪的自定义抽象服务功能。包含服务Switch Service、Mode Service、Event Service、State Service、Time Service、Rotation Service、Temperature Service以及 OTA Service，如下图 1-1。

关于比亚迪BLE GATT协议中的详细内容，请您先通过企业认证，在『管理中心 - AIoT服务平台 -开发协议』，查阅[**《⽐亚迪智能设备开放接⼊协议》**](#/researchTools/protocolDetail?id=109)。

#### **1.2 BLE OTA协议**

比亚迪BLE OTA协议用于后装IoT硬件固件版本升级迭代。IoT设备升级方式包括：备份升级、AB分区升级、不支持OTA。BLE OTA协议定义了**备份升级、AB分区升级的交互流程、帧数据格式、固件版本相关文件的命名规范和格式内容**。关于比亚迪BLE OTA协议中的详细内容，请您先通过企业认证，在『管理中心 - AIoT服务平台 - 开发协议』，查阅[**《**BYD乘用车IoT设备OTA升级协议**》**](#/researchTools/protocolDetail?id=7)。

备份升级：升级前将当前固件完整复制到独立存储的备份区，升级时，将代码升级区中的目标版本主程序文件拷贝到代码运行区，若失败则从备份区恢复。

AB分区升级：设备存储划分为A/B两个独立分区，每次升级仅更新非活动分区，升级过程中由原代码运行区跳转到新代码运行区，用户可继续使用设备，失败时自动回滚至旧分区。

#### **1.3 测试工具**

短距IoT协议测试助手是一款安卓手机（Android12及其以上版本）的应用测试工具，如下图，提供给开发者进行IoT智能设备接入比亚迪IoT生态的测试工具，用于提高开发者的测试效率和降低研发成本。短距IoT协议测试助手需要使用开放平台开发者账号登录才可以使用，该工具提供了BLE测试和OTA测试能力，用于验证IoT设备的《[比亚迪智能设备开放接入协议](#/researchTools/protocolDetail?id=109)》和[《BYD乘用车IoT设备OTA升级协议》](#/researchTools/protocolDetail?id=7)，开发者将设备固件进行测试后，会生成测试报告，同时通过该工具将报告上传到开发者平台，提交审核，该测试报告会成为接入比亚迪IoT生态的准入条件。如您需要该工具进行开发调试，请先通过企业认证，在开放平台『管理中心 - AIoT服务平台 - 研发工具研发工具->短距IoT协议测试助手』下载并安装“[短距IoT协议测试助手](#/researchTools/IoTestingAssistant)”，通过开放平台账号登录”短距IoT协议测试助手”。具体步骤可参考文档中心：[产品自测](31-产品自测.html)。
