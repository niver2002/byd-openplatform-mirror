# 合规检查要求

## **比亚迪车载生态应用软件合规检查要求**

### **1. 范围 **

本文件规定了比亚迪汽车应用市场上架的第三方应用软件合规检查要求，重点提出了应用软件开发者个人信息保护、资质提供、知识产权、法律法规、信息登记的相关要求。

### **2. 定义**

#### **2.1 个人信息personal information**

定义以电子或者其他方式记录的与已识别或者可识别的车主、驾驶人、乘车人、车外人员等有关的各种信息，不包括匿名化处理后的信息。

#### **2.2 应用软件 application software**

利用代码逻辑调用硬件能力或平台服务，实现特定服务功能的程序载体，包含APP和小程序等形态。

#### **2.3 用户 user**

使用移动互联网应用软件的个人信息主体。

#### **2.4 权限申请 system permission request**

移动互联网应用软件向移动智能终端操作系统声明,并向用户请求授权,以获得访问数据或功能的许可的过程。

#### **2.5 SDK**

软件开发工具包（Software Development Kit）

### **3. 个人信息保护要求**

#### **3.1 应用软件不应存在违规收集个人信息行为**

违规收集个人信息的行为包括未见明示、有明示未同意、明示不清晰、同意不清晰、默认同意和拒绝同意，出现上述任意一种行为，则判定为违规收集个人信息。

#### **3.2 应用软件不应存在超范围收集个人信息行为**

超范围超频次收集个人信息的行为包括超范围收集、静默后台超范围收集，出现上述任意一种行为，则判定为超范围超频次收集个人信息。

#### **3.3 应用软件不应存在违规使用个人信息行为**

违规使用个人信息的行为包括未明示共享、未同意共享、明示共享不清晰，出现上述任意一种行为，则判定为违规使用个人信息。

#### **3.4 应用软件不应存在强制用户使用定向推送功能行为 **

强制用户使用定向推送功能的行为包括未标明定推、未明示第三方个人信息来源、未标识定推、未提供关闭选项，出现上述任意一种行为，则判定为强制用户使用定向推送功能。

#### **3.5 应用软件不应存在强制、频繁、过度索取权限行为**

强制频繁过度索取权限的行为包括未同步告知目的、未经同意变更权限状态、不给权限强制退出或关闭、不给权限进行弹窗循环、申请无关权限、过度申请权限、频繁申请权限，出现上述任意一种行为，则判定为电信和互联网服务强制、频繁、过度索取权限。

#### **3.6 应用软件不应存在频繁自启动和关联启动行为**

应用软件出现下述任意一种行为，则判定为频繁自启动或关联启动：

1、应用软件未向用户明示或未经用户同意进行自启动；

2、非服务所必需或无合理应用场景，应用软件自启动或关联启动其他服务；

3、应用软件关联启动其他服务前，未显著告知用户即将跳转的其它服务或未由用户主动发起。

#### **3.7 应用软件不应存在欺骗误导强迫用户行为**

欺骗误导强迫行为包括信息窗口关不掉、欺骗误导强迫下载、安装、使用服务、应用难卸载和欺骗误导强迫点击跳转，出现上述任意一种行为，则判定为欺骗误导强迫行为。

#### **3.8 应用软件不应存在欺骗误导用户提供个人信息行为**

非服务所必需或无合理场景，在广告页面或功能页面，通过积分、奖励、优惠等方式欺骗误导用户提供身份证号码、人脸、指纹等个人信息的行为，则判定为欺骗误导用户提供个人信息。

### **4. 合规审查要求**

#### **4.1 资质提供要求**

1、应用发布上架，需提供真实有效的《计算机软件著作权证书》（或《APP电子版权认证证书》）；

2、应用发布上架，需按相关规定履行APP、ICP备案手续。未履行备案手续的，不得从事APP互联网信息服务；

3、应用内需在显著位置展示APP备案编号，并支持备案编号可点击跳转至备案系统供用户查询；

4、应用应保证具有从事相关行业的资质，资质要求可参考附件：特殊行业资质要求；

5、资质需保证真实，不得伪造或盗用其他产品信息，且始终保持资质在有效期内。

#### **4.2 知识产权要求**

开发者须确认提供的应用为原创或获得合法授权，不得在未经授权的情况下，使用他人的成果。应用应符合以下要求，如存在侵犯他人知识产权的情况，比亚迪有权下架违规应用，并拒绝应用发布和更新申请。

1、应用不得以误导用户的方式使用与其他开发者应用相同或相似如外观、名称、主题等。应用不得使用不当方式或在未经授权的情况下使用相同或相似商标，可能导致用户对相关商品的来源造成混淆；

2、开发者需获取许可授权，才能在应用内使用他人知识产权成果；

3、游戏类应用不得为有明确版权归属的破解版、汉化版；

4、应用及其内容不得侵犯他人在先权利，也不得以帮助、诱导等方式间接侵犯他人在先权利。

#### **4.3 内容管理要求**

1、应用不得含有违法内容或其他敏感信息，包括但不限于涉政、涉赌、暴力、色情、性暗示及广告法中不允许使用的词汇；

2、应用不得带有诽谤、人身攻击或者侮辱个人或者团体；

3、应用不得对武器进行过于逼真的表述（如不能涉及武器的制造工艺和参数等），并鼓励违法或滥用武器；

4、应用不得存在反政府、反社会或者不符合主流政治、存在国家法律禁止的行为；

5、应用内容存在安全隐患、其他不友好信息或违规违法嫌疑信息；

6、应用内实际内容与应用内描述或平台信息不符，构成虚假宣传或者误导用户。
