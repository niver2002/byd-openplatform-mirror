## **高阶配置概述**

比亚迪生态开放平台的高阶配置功能，专为接入车机智慧物联App的智能设备设计。高阶配置包括：

- 产品百科

  ：配置产品说明书、产品主图、产品卖点文案，该信息在车机智慧物联App呈现，并且支持国际化配置。
- 手动添加引导

  ：配置设备联网图示，设备初始化说明等，该信息将引导用户在车机智慧物联App中添加产品，并且支持国际化配置。

注意：高阶配置中每一项可以单独提交审核。如审核未通过，需要修改后重新提交。
