## **接入指南**

### **1. 接入流程总览**

主题接入[比亚迪生态开放平台](#/dashboard/analysis)，需要进行以下步骤：

**开发者注册 > 实名认证 > 设计师信息填写 > 作品上传 > 提交审核 > 审核通过后正式上架。**

### **2. 开发者注册认证**

开发者访问[比亚迪生态开放平台](#/dashboard/analysis)，点击右上角的“**注册/登录**”，首先注册比亚迪生态开放平台账号（此操作不需审核）。如果您需要上传主题，还需在右上角的用户下点击“**去认证**”，填写所需信息成为认证用户。

### **3. 开发者账号审核**

账户注册不需要审核。提交后即完成比亚迪账户注册。

实名认证一般需要**3-5个工作日**的审核时间。您可以通过登录[比亚迪生态开放平台](#/dashboard/analysis)查询结果。

### **4. 填写设计师信息**

首次上传主题前需要完成设计师信息填写。点击“管理中心”-“作品管理”-“设计师信息”进行填写。

![image.png](../assets/258d3846ca4c4bf1811abc46adfdf1b2-17d961.png)

图4-1 设计师信息填写示例1

填写设计师名称、英文名称、个人简介、获取来源、设计师类型、平台认证与专业背书、粉丝量级、IP知名度、其他资料信息。

|  |  |
|---|---|
| 填写字段 | 填写说明 |
| 设计师名称 | 该名称会出现在主题详情中展示给用户，不可修改，请认真填写 |
| 平台认证与专业背书 | 上传内容包括但不限于获奖证书、设计师资格证书、简历等， 此部分内容将有助于提升主题审核评分 |
| 粉丝量级 | 选择对应的粉丝量级后需要上传自媒体平台截图，没有则不用上传， 此部分内容将有助于提升主题审核评分 |
| IP知名度 | 根据实际情况选择，需上传IP简介和合作案例材料，没有则不用上传， 此部分内容将有助于提升主题审核评分 |
| 其他资料 | 若有需要补充的其他资料可在此上传 |

表 4-1 设计师信息填写说明

以上信息填写完成后点击“保存”。

### **5. 上传主题**

点击“主题列表”-“新增”进入主题编辑器，编辑好资源后提交主题，编辑器会自动打包资源并直接提交到开放平台：平台主题列表自动生成待提交记录，编辑器中已填写的主题信息自动回填，可参考[主题编辑器使用说明](353-主题编辑器使用说明.html)。

### **6、补充审核资料**

根据平台主题列表自动生成待提交记录、点击编辑审核信息，补充相关信息后提交。**（注：由于比亚迪旗下品牌、车型众多，且不同平台、屏幕尺寸及车机版本对主题包的适配要求不同，因此在编辑器中提交主题时，系统会自动按平台、屏幕尺寸等维度生成多个待提交记录。这并非重复提交，请按提示将多条记录全部提交完成，以确保主题在各车型上正常适配展示）**

### **7. 审核**

主题提交后可在主题列表查看已创建的主题及主题审核状态，显示“审核中”表示主题上传成功，请耐心等待审核结果，通过后状态变更为“审核通过”。

### **8. 上架**

主题审核通过后，经过官方测试无问题将上架比亚迪车机百变主题APP，上架后会通过生态开放平台消息中心与短信的方式提醒您，此时主题状态变更为“已上架”，可在比亚迪车机百变主题APP查看您的主题。
