## **『basa』车载吸尘器**

### **1. 车机联动功能**

basa车载吸尘器，通过蓝牙协议接入“智慧物联APP”。用户通过车机大屏，可以查看吸尘器的状态，包括滤芯寿命、清扫时长、低电量显示。

![image.png](../assets/84b005b7ad754b2485929cd6fdaf148f-3a759e.png)

图 1-1 basa车载吸尘器

### **2. 车机大屏显示和操控**

车机大屏显示车载吸尘器的信息有：

- 滤芯寿命；
- 清扫时长；
- 低电量提示；

当用户替换滤芯后，可以在车机大屏重置滤芯寿命，如图 1-3。

![image.png](../assets/5c0e7b8e223f42208e226c6da13566f4-695fed.png)

图 2-1 车机大屏显示和操控

![image.png](../assets/8986e91f2d0b4d2e9f1231ac6633f3a6-a59c25.png)

图 2-2 车机大屏重置滤芯

### **3. 车机语音提示**

- 当用户超过2个月未使用吸尘器，打开车机智慧物联App，车机智能语音会提示用户。
- 当打开App时，识别到用户本周第2次使用吸尘器，智能语音会鼓励用户。
