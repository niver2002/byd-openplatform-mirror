# 儿童座椅

> 来源：AIoT业务 / 合作案例 / 直连接入 / 儿童座椅 · https://openplatform.byd.com/#/document/index?id=12

**『好孩子』智能儿童座椅**

### **1. 车机联动功能**

好孩子智能儿童座椅通过蓝牙协议接入“智慧物联APP”，用户通过车机大屏或者车内语音助手，实现对儿童座椅旋转、座椅通风、俯仰角度调节等功能。同时为用户提供各类场景自动化功能选择，包括“宝宝入睡”、“宝宝迎宾”、“儿童座椅回正”。

![画板.jpg](../assets/cadbba672b6c410e9a6754c409944eaa-903e41.jpg)

图 1-1 车机端儿童安全座椅联动

#### **1.1. 车机大屏控制**

***——方便一人带娃出行***

车机大屏控制座椅的功能有：

- 座椅旋转；
- 座椅通风开启、停止，风量大小1、2、3档调节；
- 座椅俯仰角度无极调节；

图 1-2 车机端座椅俯仰角度无极调节

#### **1.2. 车机语音控制**

**——*****行车中可以安全调整***

车机智能语音控制座椅的功能有：

- 座椅旋转；
- 座椅通风开启、停止，风量大小1、2、3档调节；

![画板 2.jpg](../assets/03e3f98de97d401a90fd2d8d79b74e87-fb2877.jpg)

图 1-3 车机端智能语音控制座椅

#### **1.3. 场景自动化功能**

**——*****时刻考虑细节与便利***

车机端座椅自动化的功能在“智慧物联APP->场景->宝宝出行”场景分类中，具体有如下场景模式：

- 宝宝入睡；
- 儿童座椅回正；
- 右侧宝宝迎宾；
- 左侧宝宝迎宾；

### 2. 手机显示功能

**——*****支持远程查看状态***

从比亚迪手机App进入儿童座椅的界面，其他家长可以远程查看座椅状态。
