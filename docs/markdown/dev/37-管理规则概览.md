##### **管理规则概览**

为切实保障消费者合法权益，维护比亚迪商城经营秩序，构筑公平诚信的电商生态环境，特制定以下管理规则。以下规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。
