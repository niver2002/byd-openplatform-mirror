# 第三方商家违规处理规则

> 来源：营销渠道 / 规则中心 / 第三方商家违规处理规则 · https://openplatform.byd.com/#/document/index?id=233

##### **第三方商家违规处理规则**

###### **一、概述**

###### **1.1 目的**

为保障比亚迪商城的经营秩序，保护消费者与合规经营商家的合法权益，现对商家违规行为分为“严重违规行为”与“一般违规行为”两类进行管理。

###### **1.2 适用对象**

本规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。

###### **二、违规处理流程**

###### **2.1 违规判定**

比亚迪商城基于主动排查、消费者投诉、权利人举报、新闻媒体曝光、行政管理部门的通知、司法机关的法律文书及其他合法合规渠道对第三方商家经营行为进行违规判定。违规判定过程中，第三方商家须按比亚迪商城要求配合提供相关材料及说明。

###### **2.2 违规处理**

违规判定完成后，比亚迪商城将违规结果通知告知第三方商家，并依据本规则中的“违规处理措施”，对第三方商家进行行为纠正或违规处罚。

###### **2.3 申诉处理**

第三方商家如对违规判定结果有异议，可依据《第三方商家申诉规则》，在规定申诉时效内通过联系邮件openplateform@byd.com向比亚迪商城发起申诉，并按要求提交相关证明材料。

###### **三、严重违规行为**

严重违规行为是指严重破坏比亚迪商城经营秩序、侵害消费者权益或违反国家法律法规的行为。

###### **3.1 商品与资质类违规**

（1）出售假冒商品：第三方商家出售假冒、盗版商品的行为。

（2）出售质量不合格商品：第三方商家出售的商品品质不符合国家标准、行业标准、平台标准或商家自身承诺的标准。

（3）出售违规商品：第三方商家出售《禁止发布商品及信息清单》中的商品或其他法律法规禁止的商品。

（4）提供虚假证照：第三方商家在入驻或经营过程中，提供虚假的营业执照、行政许可等资质文件。

###### **3.2 信息与营销类违规**

（1）发布违禁商品信息：第三方商家发布涉黄、涉暴、涉毒或违反公序良俗、国家法律法规的信息，或发布《禁止发布商品及信息清单》中的商品信息。

（2）严重虚假宣传：

①宣传售卖的商品与消费者实收商品，存在明显不一致（包含但不限于：类型、款式、规格、数量、功效等），且商家刻意规避平台管理（如刻意遮挡、使用错别字/特殊符号/行业暗语言等方式进行商品描述或展示）；

②功效严重虚假宣传：宣传或暗示售卖商品对重大疾病有效果（如恶性肿瘤、尿毒症、瘫痪等），宣传或暗示售卖商品有特殊功效（如减肥、壮阳、丰胸、增高等），但商品实际并不存在相应功效；

③因虚假宣传引发司法调查、行政监管、行政诉讼、媒体报道、公众质疑、负面舆论、舆情事件，或对于消费者造成人身伤害或经济损失。

（3）知识产权侵权：指商家所使用的宣传推广内容，涉及侵害他人商标权、专利权、著作权等权利的行为。

###### ** 3.3 交易与服务类违规**

（1）虚假交易：第三方商家通过虚构交易、虚构评价等方式，获取虚假的商品销量、评价、店铺评分等不当利益。

（2）拒绝承担赔付义务：经比亚迪商城介入判定，第三方商家应承担违规责任并进行赔付，但在无正当理由的情况下拒绝履行。

（3）拒绝提供“三包”服务：第三方商家在无正当理由的情况下，拒绝依照国家规定或与消费者的约定提供“三包”服务。

###### **3.4 隐私与人身权益类违规**

（1）泄露他人信息：商家未经允许发布、泄露、传播消费者或其他第三方的个人信息，侵犯他人隐私权或产生个人数据泄露。

（2）恶意骚扰：商家通过电话、短信、邮件等方式，对消费者或其他第三方实施侮辱、恐吓、诋毁等行为，妨害他人合法权益。

###### **四、 一般违规行为**

一般违规行为是指除严重违规行为外，影响用户体验和平台正常经营秩序的违规行为。

###### **4.1 商品与资质类违规**

（1）发布非约定商品：商家未经比亚迪商城允许，发布或出售超出其授权品牌或经营类目的商品。

（2）未及时更新资质文件：商家在入驻或经营过程中，未按平台要求提交或更新营业执照、行政许可等资质文件。

###### **4.2 信息与营销类违规**

（1）虚假宣传：因商家非主观故意的失误（如信息录入错误、仓储发错货等），导致宣传售卖的商品与消费者实收商品，存在不一致（包含但不限于：类型、款式、规格、数量、材质、效果等）。

###### **4.3 交易与服务类违规**

（1）未按标准提供售后服务：商家未按照《第三方商家售后服务管理规则》进行咨询答疑、退换货服务及其他售后服务，存在消极服务、无故拒绝售后等情况。

• 消极服务：包括服务过程中嘲讽贬低消费者；单日或自然周内存在大量不响应（无人工客服应答）、响应慢（平均响应时长＞90秒）、应对消极（客服让消费者等待但无后续答复，或回复内容与消费者诉求无关）等情况；

（2）服务承诺未履行：商家未兑现其向消费者承诺的各项服务（除“三包”等严重违规行为涵盖的核心服务外）。

###### **五、违规处理措施**

为维护比亚迪商城的健康交易环境，保障消费者与商家的合法权益，比亚迪商城将根据商家违规行为的性质与情节，采取以下处理措施：

###### **5.1 如商家行为构成严重违规，比亚迪商城有权采取以下一项或多项措施：**

（1）对涉及违规的商品进行下架处理；

（2）依照保证金存缴等级，每次扣除对应金额的保证金。

|  |  |  |
|---|---|---|
| 公司规模 | 经营类目 | 单次扣除保证金金额（元） |
| 0人<公司员工<20人或个体工商户 | 软件、会员等无形产品 | 500 |
| 硬件等有形产品 | 2500 |  |
| 20人≤公司员工＜1000人 | 软件、会员等无形产品 | 1500 |
| 硬件等有形产品 | 10000 |  |
| 1000人≤公司员工 | 软件、会员等无形产品 | 2500 |
| 硬件等有形产品 | 25000 |  |

（3）单月内累计严重违规达两次及以上，比亚迪商城有权终止与该商家的合作。

（4）如违规情节特别严重，造成的损失超过保证金总额，比亚迪商城有权直接从保证金中扣除相应金额后，继续向商家追偿。

###### **5.2 如商家行为构成一般违规，比亚迪商城有权采取以下一项或多项措施：**

（1）对商家发出违规通知，并要求商家在指定期限内完成整改；

（2）单月内累计一般违规达三次，依照保证金存缴等级，每次扣除对应金额的保证金。

|  |  |  |
|---|---|---|
| 公司规模 | 经营类目 | 单次扣除保证金金额（元） |
| 0人<公司员工<20人 | 软件、会员等无形产品 | 500 |
| 硬件等有形产品 | 2500 |  |
| 20人≤公司员工＜1000人 | 软件、会员等无形产品 | 1500 |
| 硬件等有形产品 | 10000 |  |
| 1000人≤公司员工 | 软件、会员等无形产品 | 2500 |
| 硬件等有形产品 | 25000 |  |

（3）情节严重或多次违规未改的，比亚迪商城有权对相应商品进行下架处理。

（4）如违规情节特别严重，造成的损失金额超过保证金总额，比亚迪商城有权直接从保证金中扣除相应金额后，继续向商家追偿。

###### **5.3 比亚迪商城有权在法律法规允许范围内，对第三方商家违规行为及处理结果进行公示。**

###### **六、附则**

6.1 规则变更：比亚迪商城有权根据业务需要或法律法规变化随时调整本规则。调整后的规则通过比亚迪生态开放平台向商家公示后生效。如商家不同意变更，可书面提出异议并停止使用相关服务；若商家在变更生效后继续使用服务，即视为接受变更后的规则。

6.2 生效时间：本规则于2026年1月1日首次发布，自2026年1月1日起正式生效。
