比亚迪亮相WAIC2026

来源：活动与动态 / 比亚迪亮相WAIC2026 · 文档 ID 340 · 原始页面

以车为核心，链接一切 | 比亚迪智慧生态亮相2026世界人工智能大会

2026年7月17日至20日，2026世界人工智能大会（WAIC）在上海世博、张江、西岸三大片区举办。作为由九大部委联合主办的全球顶级AI行业盛会，本届大会以“智能伙伴，共创未来”为主题，汇聚全球1100余家企业、超3000件展品参展。

比亚迪集团携多项前沿科创与出行安全成果亮相本次大会，集中展出芯片、闪充技术、天神之眼辅助驾驶技术与最新一代智慧生态成果，围绕补能效率、行车安全、芯片制造与智慧生态四大维度展现技术落地成果，践行“让前沿出行科技人人可享，人人放心享”的理念，携手行业共同探索安全、高效、可靠的未来出行解决方案。


核心技术落地 筑牢出行效率与安全底座

比亚迪现场重磅展示中国首款4nm车规级智驾芯片“璇玑A3“，支持L3/L4自动驾驶，三颗芯片协同可实现超2100TOPS总算力。结合自研算法深度优化后，算力利用率提升100%，辅助驾驶响应更快，处理复杂问题能力更强，安全上限更高。同时，比亚迪超级智能体“迪迪虾”，赋能DiLink AI智能座舱，具备“聊得来、搞得定、玩得转”三大硬核能力。还有比亚迪闪充，可以实现5分钟充好、9分钟充饱，在零下30℃低温环境下，补能时长仅增加3分钟。在行车安全领域，比亚迪率先承诺为城市领航、智能泊车提供双兜底保障，全方位守护用户全场景行车安全。


手车互联全品牌覆盖 打造无缝跨端交互体验

在手车互联领域，比亚迪率先实现行业首家国内主流手机品牌全覆盖，集齐八大手机品牌适配能力，可无缝支持OPPO、华为、小米、vivo、荣耀、三星等主流手机品牌。

技术层面，比亚迪实现多项行业首创。与CarLink、HUAWEI Hicar、荣耀车联三大协议均达成行业首发镜像模式，用户在连接手车互联的状态下，仍可完整操作原生车机系统；Carlink镜像投屏搭配隐私模式，支持用户自主选择可在车机端显示的应用，未同步的应用可在手机端独立运行，有效保护用户隐私，并同时支持镜像模式和隐私模式一键切换。语音融合技术实现“一次唤醒小迪，全场景控制”的跨品牌统一语音交互体验。

此外，比亚迪手车互联方案还集成摇一摇导航流转、网络共享、文件互传等实用功能，构建起从连接、交互到数据流转的完整生态闭环。


全场景智能服务 重构人车交互体验

比亚迪以“车+生活”为核心，联合生态伙伴共建全场景Agent服务体系，推出车生活Agent功能，用户在车内通过语音指令即可完成停车、订座、点餐等全链路生活服务需求，重新定义“人-车-生活”的智能化体验。

在智能穿戴设备联动领域，比亚迪同样取得行业领先地位，成为行业第一家集齐苹果、华为、OPPO三大品牌手表车控功能的车企。同时，比亚迪与支付宝深度合作，实现行业首发蚂蚁森林车机版，将环保理念融入日常出行场景。


开放生态持续升级 构建“人-车-家”全链路闭环

比亚迪的开放生态战略始于2018年发布的开放生态1.0版本，并于2025年3月正式进行战略升级，核心目标是打破生态壁垒，构建跨设备、跨场景的智能连接体系。

技术底座层面，比亚迪于2025年3月发布行业首个IoT协议“AutoIoT”，为跨生态设备互联提供统一技术标准；同年8月，智慧物联开发者平台正式对外发布，聚焦车载及车周边场景，为智能硬件开发者提供全栈式技术赋能。

生态合作层面，比亚迪已联合80余家生态合作伙伴共同搭建智慧生态体系。其中与美的达成的战略合作，实现车控家与家控车双向互联，覆盖3大场景、11类家居设备，打破车与家的物理场景边界。

目前，比亚迪正加速构建“以车为核心，链接一切”的开放生态体系，依托软硬件标准协议，打造国内最完整的“人-车-家”智慧生态闭环，重新定义智慧出行时代的人车关系。通过深度融合AIoT技术、应用分发与主题共创生态，比亚迪为智能硬件开发者、车机应用开发者提供覆盖开发赋能、测试验证、营销运营的全链路标准化解决方案，持续推动汽车互联互通生态快速发展。
