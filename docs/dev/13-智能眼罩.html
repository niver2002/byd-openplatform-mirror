智能眼罩

来源：AIoT业务 / 合作案例 / 直连接入 / 智能眼罩 · 文档 ID 13 · 原始页面

『倍轻松』智能眼罩

1. 车机联动功能

倍轻松智能眼罩通过蓝牙协议接入“智慧物联APP”，用户通过车机大屏或者车内语音助手，实现对智能眼罩热敷、按摩、模式调节等功能。

图 1-1 眼罩车机联动

1.1 车机大屏控制

  • 模式支持“美眼”、“护眼”、“睡眠”三种模式切换;
  • 振动强度支持“关闭”、“轻柔”、“适中”、“强劲”四挡调节;
  • 温控支持“低档”、“高档”两档调节;

图 1-2 车机端智慧物联App眼罩控制界面

1.2 车机语音功能

车机智能语音实现了车机大屏控制眼罩的全部功能。方便用户解放双手，畅享按摩。

图 1-3 车内语音控制眼罩

1.3 车机场景自动化

小憩场景(车机大屏及车机语音功能实现)

  • 按压时长设置功能；
  • 按压时长显示功能；
  • 设备冷敷功能；
  • 设备冷热交替功能；

图 1-4 场景自动化

2. 手机控制功能

眼罩离开车机的使用场景中，手机也可控制眼罩的功能。从手机端比亚迪App的"我的->智慧物联"，选择智能眼罩，进入眼罩的控制界面，该界面可显示并控制眼罩剩余电量、冷/热敷状态、按压剩余时间、当前模式等。

图 2-1 手机控制眼罩
