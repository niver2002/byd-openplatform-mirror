禁止发布商品及信息明细

来源：营销渠道 / 规则中心 / 禁止发布商品及信息明细 · 文档 ID 227 · 原始页面

禁止发布商品及信息明细

一、概述
1.1 适用对象

本规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。

1.2 规则概述

第三方商家禁止通过比亚迪商城售卖或发布国家法律法规中明确禁止的商品或信息，包括但不限于：商品信息、交互信息等。

二、禁止发布商品及信息明细
禁发商品及信息大类禁发商品及信息细则
一、军警用品、管制器具类枪支、弹药、军火。
枪支、弹药、军火的相关器材，零部件，附属产品、仿制品及其制作方法等。
可致使他人暂时失去反抗能力，对他人身体造成重大伤害的管制器具。
管制类刀具、飞镖、弩及其配件等可能用于危害他人人身安全的器具。
危险器具、危险玩具。
军用、警用等国家机关的标志、徽章、服饰、配件、设备等专供、特供产品及其仿制品。
二、易燃易爆物品、危险化学品、毒品类易燃、易爆物品，及其发射装置。
国家禁止生产、经营、使用的危险化学品。
毒品、制毒原料、制毒化学品及致瘾性药物。
毒品吸食工具及配件、介绍制毒的方法、工艺及相关产品。
含有宣扬涉毒文化的信息。
三、危害国家与社会安全类任何破坏国家统一、社会稳定，或泄露国家机密的内容与物品。包括但不限于非法的涉政书刊、音像制品、文件资料及诈骗网站等。
宣扬恐怖主义、极端主义，煽动民族仇恨、种族歧视，破坏民族团结，破坏国家宗教政策、宣扬邪教的商品或信息。
损害国家荣誉名誉、歪曲丑化英雄烈士，以及美化侵略历史或宣扬军国主义的内容。
含有传播或评议国家政策、国家领导人、政治事件、社会事件、宗教活动及等商品或信息。
四、色情、暴力、低俗类含有淫秽内容的音频及其制品、视频及其制品、色情陪聊服务、成人网站论坛的账号/邀请码或其他淫秽物品。
可致使他人暂时失去反抗能力、意识模糊的口服或外用的催情类商品。
用于传播色情信息的软件、种子文件、网盘资源及图片。
五、侵犯他人隐私类用于监听、窃取隐私、泄露个人私密资料、手机监听器或机密的软件及设备等。
盗取或破解账号密码的软件、工具、教程及产物等。
个人隐私信息及企业内部数据，提供个人手机定位、电话清单查询、银行账户查询等服务。
用于非法摄像、录音、取证等用途的设备等。
六、药品、医疗器械类假药、劣药及其他禁止出售的药品。
未经药品监督管理部门批准生产、进口或未经检验即销售的药品或医疗器械。
七、人类健康、动植物与动物捕杀类人体器官、遗体。
人类遗传资源材料及相关服务。
病原微生物类。
国家保护类动植物及其制品，相关部门或文件禁止销售的动植物类商品。
严重危害人畜安全的动物捕杀设备或配件以及其他动物捕杀工具。
猫狗肉、猫狗皮毛、鲨鱼翅、熊胆及其制品等，以及其他有违公益或对当地生态系统可能造成重大破坏的生物物种及其制品。
八、其他类本规则虽未明确列明，但是属于国家法律、行政法规等明确禁售销售的商品及其信息。
三、违规处罚

3.1 对于违规发布上述清单中列明的商品及信息的商家，比亚迪商城有权依据《第三方商家违规处理规则》采取处罚措施，具体措施以上述规则正文为准。

四、附则

4.1 规则变更：比亚迪商城有权根据业务需要或法律法规变化随时调整本规则。调整后的规则通过比亚迪生态开放平台向商家公示后生效。如商家不同意变更，可书面提出异议并停止使用相关服务；若商家在变更生效后继续使用服务，即视为接受变更后的规则。

4.2 生效时间：本规则于2026年1月1日首次发布，自2026年1月1日起正式生效。
