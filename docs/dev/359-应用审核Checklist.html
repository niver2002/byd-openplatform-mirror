来源：应用分发业务 / 应用分发审核管理规范 / 应用审核Checklist · 文档 ID 359 · 原始页面

应用审核Checklist

应用发布前，请务必仔细研读应用市场审核指南，充分了解比亚迪应用市场上架审核的相关规则与要求，并提前备齐发布所需文件及资源，确保审核流程顺利推进。

为协助开发者做好应用上架前的准备工作，在提交审核前，请参照本清单所列事项完成自查，提前排查并整改常见问题。请确认全部检查项均已落实后，再行提交应用上架审核，审核结果以最终意见为准。

1. 适用范围

个人开发者、企业开发者

2. 开发前

阶段模块检查项修改建议
开发前应用名称应用名称是否为泛化词汇，例如「免费天气」等请规范应用名称，避免使用电话、邮件、日历等广义归纳类、缺乏识别性的通用词汇进行命名，并确保软件著作权登记证书所载软件名称与所提交的应用名称保持一致。
应用名称及图标应用名称及图标是否与其他应用存在相同或近似情形，是否使用系统默认图标1. 请提供应用名称及图标的权属证明文件，或对应用名称及图标进行修改调整；2. 代码开发阶段，应统一替换软件包内的图标。
应用功能应用市场内是否已存在较多功能同质化的应用建议审慎评估赛道竞争格局，避免在同类应用已高度饱和的品类中进行同质化开发。
应用备案是否符合监管部门关于移动互联网应用程序备案工作的相关要求请及时完成应用备案工作，确保备案信息中填报的主体信息、应用名称、应用包名与在架应用信息保持一致，并保证备案号处于有效状态。
特殊行业资质应用内容是否涉及特殊行业内容类型请对照内容类型核查清单，参照资质要求准备相应的资质证明文件。详见：特殊行业资质要求。

2-1 开发前检测项目表

3. 开发中

阶段模块检查项修改建议
开发中功能开发应用功能体验是否完整连贯，是否具备实用价值并能够为用户提供实质性的功能或服务请确保应用能够为用户提供完整、稳定、流畅且具有吸引力的功能体验。若该应用已发布其他端版本，车机端版本的功能质量与完善程度应不低于其他端版本，保障用户跨端体验的一致性。
应用自测应用是否存在崩溃、功能异常等质量问题为保障用户体验，软件包提交前应完成全面自检，及早发现并修复应用质量及体验问题。请参照自测报告相关内容逐项开展测试。
隐私合规是否通过显著方式提示用户查阅隐私政策应用首次启动时，应通过弹窗形式展示隐私政策，或在注册、登录等界面以显著方式呈现隐私政策，提示用户予以查阅。
隐私合规是否存在在用户同意隐私政策前即收集个人信息的情形请自查应用及所集成的第三方SDK，确保仅在用户同意隐私政策后，方可收集用户个人信息。个人信息的收集及权限申请均应在用户同意隐私政策之后进行。

3-1 开发中检测项目表

4. 上架提审

阶段模块检查项修改建议
上架提审软件包管理软件包是否为正式发布版本所提交的应用应为已完成自测的正式版本。
应用分屏情况应用所支持的分屏模式请选择应用支持的分屏模式，例如：5/5分屏、3/7分屏、不支持分屏、其他等。
应用适配分辨率应用适配的分辨率规格请选择应用适配的分辨率规格，例如：1920×1080、1728×1888、1920×720等。详见：屏幕信息说明。
应用适配屏幕应用适配的屏幕显示类型请选择应用支持的屏幕类型，例如：横屏、竖屏、通用（即旋转屏，可同时支持横屏与竖屏）。
应用分类标签应用分类是否与实际功能及用途相符请选择与应用实际功能及用途相符的分类。
应用接口应用是否调用车机系统接口应用提交前，请参照接口清单如实填报所调用的接口；未按要求填报的，审核可能予以驳回。
上架自检是否提前检测应用在功耗、性能、兼容性、稳定性、用户体验及隐私合规等方面存在的问题应用提交测试前，请参照自测报告完成各项测试，提前排查并整改上架环节可能存在的问题，以提升审核通过率、缩短上架周期。
可本地化基础信息应用名称及图标是否与安装后显示一致请确保所提交的应用名称及图标与应用安装后在终端显示的名称及图标保持一致。
应用审核信息测试账号信息填报是否准确完整若应用需登录后方可使用，请在提审页面的「测试账号」栏目中提供测试账号。请确保该测试账号可正常使用全部功能，不存在权限、角色、会员、付费等限制，以保障审核人员能够完成登录、浏览、操作、退出的全流程测试。
可本地化基础信息应用简介、描述及预览图是否与应用实际情况相符1. 请提交与应用实际功能内容相符的应用信息，包括应用图标、应用简介、应用描述、版本更新说明及应用预览图，避免误导用户。2. 请删除「国家级、最高级、最佳」等不符合《广告法》规定的相关表述。3. 请删除「test、demo、beta」等表明应用为测试版本或测试数据的词汇。详见：应用市场审核指南。
备案信息是否已完成备案请及时完成应用备案工作，确保备案信息中填报的主体信息、应用名称、应用包名与在架应用信息保持一致，并保证备案号处于有效状态。
备案信息备案信息填报是否准确完整若应用备案信息中的应用包名、应用名称、主体信息与在架信息不一致，可能导致备案校验不通过。请注意，填写「主体证件号」时，应注意区分「数字5」与「字母S」、「数字1」与「字母I」、「数字0」与「字母O」。
版权信息应用内容是否涉及特殊行业内容类型请参照特殊行业资质要求上传相应的资质证明文件。
资质信息应用软件是否授权上架请按照应用软件授权书模板签署后上传。
资质信息隐私政策链接是否可正常访问请确保隐私政策链接可正常访问
资质信息用户协议链接是否可正常访问请确保用户协议链接可正常访问
自检信息竞品分析报告内容是否完整请按照竞品分析报告模板完成编制，并上传。
自检信息准入标准审核表是否填写齐全请按照准入标准审核表模板填写完毕，并上传。
