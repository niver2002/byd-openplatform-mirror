交易纠纷仲裁规则

来源：营销渠道 / 规则中心 / 交易纠纷仲裁规则 · 文档 ID 231 · 原始页面

交易纠纷仲裁规则

一、概述
1.1 适用对象

本规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。

1.2 适用情形

当第三方商家与消费者因商品销售、物流、售后服务等问题无法协商一致，消费者或商家申请比亚迪商城介入时，比亚迪商城将依据本规则处理。

二、受理期限和范围
2.1 受理期限

2.1.1 若对商品或服务产生争议，消费者可自下单并完成付款后提出维权主张，但向本平台发起投诉的期限，最长不得超过法律规定的诉讼时效期间，本平台另有规定的除外。

2.1.2 消费者就“三包”服务或商家提供的其他服务提起投诉，应在该服务的法定有效期或商家承诺的有效期（以二者中时间较长者为准）内提出。

2.1.3 下列情形不受前述受理期限的限制：

（1）行政机关或具备合法资质的鉴定机构认定商家产品为假冒或违禁商品；（2）依据法律规定，或基于行政机关、司法机关的生效法律文书或决定，本平台有义务处理的；（3）商家销售的商品或提供的服务不符合保障人身、财产安全要求的。

2.2 受理范围

2.2.1 本平台受理在比亚迪商城上产生的交易争议处理申请，但出现以下情形时，平台可不予受理，建议买卖双方自行协商解决，或通过司法途径等向相对方主张权利：

（1）消费者未在本规则规定的受理期限内发起维权；

（2）交易订单显示的商品或服务与双方实际约定不一致，导致交易事实无法查清；

（3）买卖双方经自行协商达成退款或退货退款协议并履行完毕，一方或双方反悔产生争议；

（4）交易做退款处理后，因卖家需要取回商品产生争议；

（5）买卖双方进行虚假交易；

（6）消费者发起投诉时商家已退出比亚迪商城。

三、纠纷处理规则

3.1 买卖双方就交易商品或服务的具体内容已有约定的，从其约定，但相关约定违反法律法规的除外；若双方未作约定或约定不明，且无法就相关内容达成一致的，比亚迪商城在介入处理纠纷时，有权依据商城规则进行处理。如未对特定纠纷情形作出规定，比亚迪商城有权依据国家法律法规、同类交易习惯及其他合理依据作为纠纷处理参考。

3.2 在争议解决过程中，买卖双方应对各自提出的主张及时提供相应证明材料。消费者主张商家存在违反平台规则行为的，应提交初步证明材料，包括但不限于：相关订单信息、对商家违规行为的描述、商品实物照片、与商家的沟通记录，以及平台要求的其他资料（如有）。商家主张不存在消费者所指违规行为的，应按照平台要求提供证明材料，包括但不限于：产品合格证明、宣传材料真实性证明、维修服务记录、换货/退货/退款服务凭证、物流信息及相关证明，以及平台要求的其他文件。

3.3 商家将发货商品交付承运人后消费者签收前，商品风险由商家承担。

除特殊规定外，交易做退货退款处理的，或商家同意退货但无确切证据证明商家有责的，消费者将退货商品交付承运人后，商品的破损风险由商家承担；商品的损毁、灭失风险由消费者承担，消费者有权向承运人求偿。

3.4 消费者投诉商家存在侵犯消费者权益或违反承诺的行为时，比亚迪商城有权依据与商家的协议、平台规则及消费者提交的证明材料，基于普通人的认知水平，对相关证明材料进行审核，判断商家是否应承担赔付义务。

3.5 在纠纷处理过程中，比亚迪商城有权通过平台系统、电子邮件、短信、电话等方式，向买卖双方发送与纠纷处理相关的通知或提示信息。

3.6 如商家行为违反比亚迪商城相关规则，比亚迪商城有权依据规则对商家进行相应处理；如商家行为违反法律法规，比亚迪商城有权依法并在平台规则范围内，对相关违法违规行为进行公示。

四、附则

4.1 规则变更：比亚迪商城有权根据业务需要或法律法规变化随时调整本规则。调整后的规则通过比亚迪生态开放平台向商家公示后生效。如商家不同意变更，可书面提出异议并停止使用相关服务；若商家在变更生效后继续使用服务，即视为接受变更后的规则。

4.2 生效时间：本规则于2026年1月1日首次发布，自2026年1月1日起正式生效。
