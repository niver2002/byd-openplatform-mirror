主题设计规范

【更新时间】：2026年9月14日

1. 概述

1.1 主题壁纸要求

安全优先：信息识别≤2秒，避免高饱和色、复杂动态，减少驾驶干扰。

可读优先：文字与背景对比度≥4.5:1，符合无障碍标准。

体验一致：仅调整视觉风格，核心功能、操作逻辑、布局不变（例：可交互APK，不可干扰桌面默认交互逻辑）。

多场景适配：兼容昼夜光线、不同屏幕及多屏联动，保障全工况清晰度。

表2-1 壁纸规格要求

注：当前付费主题仅开放动态主题类型，创作者须制作动态视频进行上传，动态视频须保证首尾帧一致，避免循环播放时出现跳帧、闪烁或画面突变。

2.1.1 横屏适配方式

  • 横屏输出16比9壁纸资源，16比9比例的屏幕会等比缩放，16比10的屏幕先缩放再裁切左右边缘

2.1.2 竖屏适配方式

图 2-3  竖屏适配方式

2.2 副驾壁纸

  • 支持格式

副驾壁纸暂时不支持动态视频和可交互apk，支持png/jpg

  • 输出尺寸

副驾尺寸：2560*720px

  • 输出建议

背景高斯模糊，对清晰度和码率要求不高，建议输出JPG节省资源空间。

  • 适配方式

按照32比9输出，24比9屏幕自动裁切左右边缘

图 2-3  副驾屏适配方式

3. 图标规范

3.1 数量、尺寸要求

必做图标68个，包含通用图标及第三方图标。

应用图标切图尺寸144px，如非矢量图，建议设计尺寸288px，设计资源应满足最小应用场景72px下图标辨识度

图标应用于【桌面卡片】场景，物理像素尺寸112px；

图标应用于【Dock栏】场景，物理像素尺寸72px；

图标应用于中控【应用中心】页面，物理像素尺寸144px；

图标应用于副驾【应用中心】页面，物理像素尺寸108px；
