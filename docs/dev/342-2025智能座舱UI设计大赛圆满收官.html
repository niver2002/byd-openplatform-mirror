2025智能座舱UI设计大赛圆满收官

来源：活动与动态 / 2025智能座舱UI设计大赛圆满收官 · 文档 ID 342 · 原始页面

2025比亚迪智能座舱UI设计大赛颁奖典礼圆满收官

2026年7月3日，比亚迪智能座舱UI设计大赛颁奖典礼在杭州隆重举行。由比亚迪携手中央美术学院、浙江大学、同济大学、江南大学、西安美术学院共同发起的智能座舱UI设计大赛，历时数月圆满落幕。这场赛事不仅收获数百份青年设计学子的创意答卷，更创下行业历史性突破：冠军作品《心浪回响·潮起共生》成为全球首个首发即搭载于全新量产车的在校大学生原创车机作品。

此次大赛颁奖典礼在海豹08上市发布会上同步举行，12组优秀作品脱颖而出。比亚迪海洋网销售事业部总经理张卓、新技术院用户体验创新设计部总监李拓、品牌及公关处品牌营销总监方宁、比亚迪海洋网销售事业部副总经理宁利邦四位领导，逐一为获奖选手颁发奖杯及证书。

本次大赛的最高荣誉——一等奖与海洋专项奖，由西安美术学院李怡洁、周珺希、刘成果，凭借《心浪回响·潮起共生》摘得，成为当晚闪耀的双料冠军！同济大学沈海莹、斯戈泰、徐勐豪《心海奇航》，江南大学汤芸婧、孙欣慧、商瀚文《"豹抱"来啦——萌宠养成系情感化HMI设计升级》获二等奖；同济大学秦宇卿、张佳怡《抱一豹 HugMe》，江南大学曹艺轩、穆炫呈、苗雨森《PERISCOPE·潜望》，浙江大学吴宋若瑶《鱼跃 YUE》获三等奖；同济大学袁润、文祎婷、徐梦瑜《逐浪而行——BYD概念HMI设计》获用户票选最佳人气奖。

值得一提的是，在活动现场，由比亚迪海洋网总经理张卓正式官宣双奖作品完成转化落地，该作品以“心浪群岛”为全新主题，首搭上线海豹08车机。此外，张卓更是强调指出“这不仅是一次产品功能的落地，更是全球首个由在校大学生原创设计，首发搭载于量产车型的车机作品”。这意味着，青年创意已从设计图纸驶入真实座舱，成为产学研用从理念走向实践的生动范本。

作品能够顺利上机，背后离不开各大院校、选手们与比亚迪设计团队的共创合作。作品《心浪回响·潮起共生》以构建"与用户情感共生"的智能化情感座舱为核心理念，打造“心浪群岛”主题。比亚迪海洋网的标志性IP“小海”，在主题车机中化身体验官，陪大家解锁“好奇岛”“宁静岛”“沸腾岛”“冒险岛”“松弛岛”五种场景，每座小岛承载不同的情绪，用户可以根据心情切换情绪小岛，跟着小海体验每种人生。

出席本次大赛颁奖典礼的，还有来自各大高校的领导和教授：中央美术学院设计学院研究生部主任王选政，浙江大学国际设计研究院副院长、工业设计系主任张克俊，同济大学设计创意学院副院长张磊，同济大学设计创意学院副教授杜钦，江南大学设计学院产品设计系主任梁峭教授，西安美术学院设计艺术学院移动出行方向负责人雷思梦等。央美王选政教授表示：“这次大赛学生们呈现的作品，毫无疑问的都让我们看到了自主的设计美学体系，以及它在未来蕴含的巨大可能性”。

未来，比亚迪将继续与高校、青年学子一起，以开放姿态迎接更多"有感而生"的设计力量，让更多优秀设计驶入每一位用户的日常出行！
