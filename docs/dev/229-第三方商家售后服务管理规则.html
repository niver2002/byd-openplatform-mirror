第三方商家售后服务管理规则

来源：营销渠道 / 规则中心 / 第三方商家售后服务管理规则 · 文档 ID 229 · 原始页面

第三方商家售后服务管理规则

一、概述
1.1 适用对象

本规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。

二、售后服务规范

2.1 第三方商家商品的售后服务由对应商家直接提供。

2.2 第三方商家所需提供的售后服务包括但不限于：针对消费者的咨询进行答疑；处理商品退换货及退款申请；提供商品安装、调试、维修、技术培训等支持；处理消费者投诉。

2.3 对于符合国家三包范围内的商品，第三方商家应严格依据《部分商品修理更换退货责任规定》等相关法律法规的规定，履行三包责任。

2.4 第三方商家需对整体售后服务质量负责，保证客服团队的服务响应时效与服务专业水准，不得存在消极服务、无故拒绝提供售后服务等情况。

2.5 当消费者与第三方商家就售后服务问题无法达成一致时，比亚迪商城有权依据本规则或其他平台规则进行处理。

三、退换货原则
3.1 商品原因导致退换货

3.1.1 商品原因导致退货处理原则

责任类型具体描述处理原则
商家原因商品存在功能性故障或质量问题1. 商品自签收之日起七日（含）内：第三方商家应对存在性能故障或质量问题的产品进行退货、换货处理，双向运费由第三方商家承担。2. 商品自签收之日起十五日（含）内：第三方商家应对存在性能故障或质量问题的产品进行换货处理，双向运费由第三方商家承担。
商家错发、漏发商品第三方商家应主动联系消费者，及时安排补发或退款。如涉及寄回商品，双向运费由第三方商家承担。
物流原因商品在送达后出现因物流原因导致的毁损、缺件、错发第三方商家应承担相应退换货责任。

3.1.2 时间判定标准

退换货时间判定标准：以商品实际签收的次日零时起开始计算，满168小时为七天，满360小时为十五天。

3.2 七天无理由退货

3.2.1 “七天无理由退货”的定义：是指消费者购买具有支持“7天无理由退货”标识的商品后，自签收商品之日起七日内，若商品符合完好标准，消费者可向商家提起七天无理由退货申请，商家在规定时效内向消费者提供退货的保障服务。

“七天无理由退货的发起条件”：对于适用“七天无理由退货”规定且保持完好的商品，消费者在签收商品之日起七日内（自实际签收次日零时起，满168小时为七天），有权向第三方商家要求退货。

3.2.2 “七天无理由退货”适用范围

适用范围商品类型
不适用“七天无理由退货”消费者定制商品
鲜活易腐的商品
在线下载或者消费者拆封的音像制品、计算机软件等数字化商品
经消费者在购买时确认，可以不适用“七天无理由退货”拆封后易影响人身安全或者生命健康的商品
拆封后易导致商品品质发生改变的商品
一经激活或者试用后价值贬损较大的商品
销售时已明示的临近保质期的商品、有瑕疵的商品
适用“七天无理由退货”除上述商品外的其他商品

3.2.3 “七天无理由退货”商品完好标准

3.2.3.1 商品能够保持原有品质、功能，商品本身、配件、商标标识齐全的，视为商品完好。商品的外包装为商品不可分割的组成部分，退回时应当齐全、无严重破损、受污。消费者基于查验需要而打开商品包装，或者为确认商品的品质、功能而进行合理的调试不影响商品的完好。

3.2.3.2 对超出查验和确认商品品质、功能需要而使用商品，导致商品价值贬损较大的，视为商品不完好。具体判定标准如下：

商品类型判定标准
食品（含保健食品）、化妆品、医疗器械、计生用品必要的一次性密封包装被损坏。
电子电器类进行未经授权的维修、改动，破坏、涂改强制性产品认证标志、指示标贴、机器序列号等。
有难以恢复原状的外观类使用痕迹。
产生激活、授权信息、不合理的个人使用数据留存等数据类使用痕迹。
服装、鞋帽、箱包、玩具、家纺、家居类商标标识被摘、标识被剪，商品受污、受损。
3.2.3 “七天无理由退货”运费规则

“七天无理由退货”的商品，退回运费由消费者承担；若消费者与商家另有约定，则按双方约定执行。

四、返修原则

4.1 保修期内，第三方商家商品如出现功能性故障或质量问题，第三方商家应提供维修服务，维修费用与双向运费依据商家承诺的保修条款而定。

4.2 对于符合国家三包范围内的商品，第三方商家应严格依据国家规定，为商品提供维修服务，细则如下：

适用场景返修原则
产品自售出之日起七日内商品发生非消费者导致的性能故障，第三方商家应提供退货、换货或免费修理服务，双向运费由第三方商家承担。
产品自售出之日起十五日内商品发生非消费者导致的性能故障，第三方商家应提供换货或者免费修理服务，双向运费由第三方商家承担。
三包有效期内修理两次后仍不能正常使用的产品，凭修理者提供的修理记录和证明，由第三方商家负责为消费者免费调换同型号同规格的产品。如因无同型号同规格产品，或消费者不愿调换其他型号、规格产品而要求退货的，第三方商家应当予以退货。


4.3 若第三方商家需对故障商品进行返厂检测，须事先与消费者协商并明确检测所需时间。若可直接维修，则需协商并明确维修时间。

五、附则

5.1 规则变更：比亚迪商城有权根据业务需要或法律法规变化随时调整本规则。调整后的规则通过比亚迪生态开放平台向商家公示后生效。如商家不同意变更，可书面提出异议并停止使用相关服务；若商家在变更生效后继续使用服务，即视为接受变更后的规则。

5.2 生效时间：本规则于2026年1月1日首次发布，自2026年1月1日起正式生效。
