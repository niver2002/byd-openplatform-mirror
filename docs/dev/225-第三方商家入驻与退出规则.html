第三方商家入驻与退出规则

来源：营销渠道 / 规则中心 / 第三方商家入驻与退出规则 · 文档 ID 225 · 原始页面

第三方商家入驻与退出规则

一、概述

1.1 为维护比亚迪商城健康经营秩序，加强对商家及商品/服务的质量管理，比亚迪商城制定本管理规则以指引第三方商家规范入驻。

1.2 本规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。

二、入驻须知

2.1 资质合规：商家须按规则公布的类目标准提交真实、完整、有效的资质文件，并及时更新维护。

2.2 信息真实：商家须确保其填报及发布的所有信息合法、真实、不侵权，严禁资料作假等非诚信行为。

2.3 风险提示：比亚迪商城未授权任何机构代理入驻，所有入驻信息请以官网信息为准。

三、商家入驻流程

3.1 入驻流程：登录比亚迪生态开放平台→选择开发者类型→按要求提交入驻资料→入驻资料审核→入驻完成

四、入驻资质要求

4.1 商家主体资质

指标要求说明
基础资质企业开发者1. 入驻公司主体须是合法注册并有效存续的企业或个体工商户。2. 须提供营业执照扫描件并加盖公司公章。营业执照载明的营业期限须在有效范围内，且所载经营范围须能够覆盖公司拟在比亚迪商城销售的商品或服务。3. 企业须提供法人身份证正反面；个体工商户须提供经营者身份证，且身份证在有效期内。
个人开发者1. 个人为年满18周岁、具有完全民事行为能力的自然人。2. 原则上无需营业执照，但须根据比亚迪商城要求提供可证明其个人技能、资质或经营活动的辅助材料（如专业资格证书、个人工作室说明等）。3. 须提供开发者身份证正反面，且身份证在有效期内。
资信企业开发者1. 公司未被国家企业信用信息公示系统列入经营异常名录。2. 公司未被列入比亚迪供应商黑名单。
个人开发者开发者个人信用良好，无重大不良记录。
经营许可根据商家经营类目，若商品属于图书音像、医疗器械、食品、互联网文化活动等特殊类目，商家须提供对应的《经营许可证》，经营商品需包含在许可证的许可范围内，且经营资质须在有效期内。
品牌资质1. 须提供由国家知识产权局颁发的商标注册证（R标）。若商标发生过转让/变更/续展，须提供对应证明文件。2. 产品有多个商标时，需分别提供商标注册证。3. 若为品牌授权，需提供以商标持有人为源头至比亚迪商城的品牌授权链文件，确保授权来源清晰、可溯。4. 使用他人IP的，需提供IP归属证明文件及使用授权书。5. 开发者须保证其销售的商品及使用的内容不侵犯任何第三方的合法权益。

4.2 产品资质

4.2.1 所有资质文件须提供原件彩色扫描件，如提交复印件、黑白扫描件需加盖商家公章。

4.2.2 此份文件仅供参考，具体以国家和行业最新要求为准。

文件要求说明
强制性认证/备案/标识CCC认证属于国家强制性认证产品需提供3C认证（国家强制性产品认证证书），带电源适配器的产品，需出具电源适配器的3C认证。

型式试验提供可靠性、环境、震动、EMC等试验结果。

其他如涉及过敏场景，提供过敏相应认证、测试报告。

4.3  如商家经营执照发生变更，应当在三个工作日内将变更情况报送比亚迪；如商家其他资质面临失效，商家需于失效前30天及时对资质信息进行更新。

比亚迪商城有权视具体引入产品性质，要求商家提供其他资质报告。

五、终止合作

5.1 终止情形：

1）自然终止：双方合同期限届满，未提出续签的，双方合作自然终止。

2）提前终止：商家在合同期限内提出书面申请提前终止合作，经双方协商一致后，可提前终止合作。

3）被动终止：商家在合同期限内违反本规则或双方协议，比亚迪商城有权解除合作。

5.2 合作终止后：

1）商品下架：比亚迪商城将停止向商家提供服务，下架商家商品。

2）保证金退回：商家可向比亚迪商城申请退还保证金，详见《保证金管理规则》。

3）货款结算：比亚迪商城将根据结算规则，对合作终止前商家已售出的合规订单进行货款结算。

4）资料保存：商家须在合作终止后按规定时限自行备份并保存其经营数据。

六、其他

6.1 规则变更：比亚迪商城有权根据业务需要或法律法规变化随时调整本规则。调整后的规则通过比亚迪生态开放平台向商家公示后生效。如商家不同意变更，可书面提出异议并停止使用相关服务；若商家在变更生效后继续使用服务，即视为接受变更后的规则。

6.2 生效时间：本规则于2026年1月1日首次发布，自2026年1月1日起正式生效。
