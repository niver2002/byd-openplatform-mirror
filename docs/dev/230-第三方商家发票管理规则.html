第三方商家发票管理规则

来源：营销渠道 / 规则中心 / 第三方商家发票管理规则 · 文档 ID 230 · 原始页面

第三方商家发票管理规则

一、概述
1.1 适用对象

本规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。

1.2 适用情形

本规则适用于消费者通过比亚迪商城下单第三方商家商品后申请开票的情形。

二、发票管理规范

2.1 《中华人民共和国电子商务法》第十四条规定，电子商务经营者销售商品或者提供服务应当依法出具纸质发票或者电子发票等购货凭证或者服务单据。电子发票与纸质发票具有同等法律效力。第三方商家如无法开票，可通过当地税务局代开发票。

2.2 第三方商家应根据实际交易情况开具真实、合法、有效的发票，并对发票开具结果负责。

2.3 第三方商家应基于消费者实际支付金额，并结合其在申请开票时填写的发票信息（包括但不限于发票抬头、金额、数量及发票用章等）开具发票。如对信息存疑，商家应主动与消费者核实。

2.4 第三方商家应保存其开具的发票，保存期自开票年度结束起算，为期十年。保存形式包括但不仅限于纸质发票原件、电子发票版式文件及对应台账；保存期间内，比亚迪商城因合规抽检、政府审计、税务协查需要，可提前三个工作日向第三方商家发出书面通知，第三方商家应在收到通知后三个工作日内向比亚迪商城提供完整、真实的发票资料，并配合查验。

2.5 发票类型：第三方商家应支持开具电子或纸质版的增值税专用发票、增值税普通发票等不同发票类型。

2.6 开票金额规则

开票场景开票金额规则
部分退款后申请开票发票金额应为扣除退款后的实付金额。
在开票后申请部分退款商家可于退款完成后，按实际支付金额重新开具发票。
订单已全额退款成功商家不再受理该订单的开票申请。
在开票后申请全额退款退款成功后原发票作废，商家无需再次开票。如发票为纸质发票，消费者应当在退货时将发票一并退回。如消费者未退回或发票遗失，商家有权在退款时扣除相应发票税款。

2.7 开票时效

2.7.1 电子发票：第三方商家应在接到消费者开票申请后10个工作日内开出电子发票，并回传至与消费者约定的发票接收渠道中。

2.7.2 纸质发票：第三方商家应在接到消费者开票申请后10个工作日内开出纸质发票且寄出，并将发货单号回传消费者。

2.8 纠纷处理

2.8.1如消费者未在规定或约定时间内收到发票，或发票存在开错的情形，且第三方商家与消费者无法达成一致的，消费者可依据《交易纠纷仲裁规则》要求比亚迪商城介入处理并进行举证。

2.8.2 消费者需提交的举证材料包括：第三方商家错开发票的证明、与商家达成发票开具约定的沟通记录等材料。

第三方商家如存在异议，需提交的举证材料包括：发票开具底单及消费者签收凭证。若商家主张未收到消费者退回的发票，则须提交由快递公司盖章确认的收货证明，或能体现消费者承认未退票的客服沟通记录等证据。

2.8.3 如第三方商家未按时完成开票或纸质发票寄送时效要求的，比亚迪商城有权按照《第三方商家违规处理规则》对第三方进行处罚。如与消费者再次协商发票开具，第三方商家最迟应在2个工作日内为消费者开具并寄出。

2.8.4 如存在发票开错的情形，第三方商家需与消费者协商原发票寄回与新发票重开的时间。如双方达成一致，则以双方约定时间为准；如无明确约定，第三方商家需在比亚迪商城判定责任后2个工作日内为消费者重开并寄出。

三、附则

3.1 规则变更：比亚迪商城有权根据业务需要或法律法规变化随时调整本规则。调整后的规则通过比亚迪生态开放平台向商家公示后生效。如商家不同意变更，可书面提出异议并停止使用相关服务；若商家在变更生效后继续使用服务，即视为接受变更后的规则。

3.2 生效时间：本规则于2026年1月1日首次发布，自2026年1月1日起正式生效。
