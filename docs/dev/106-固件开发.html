来源：AIoT业务 / 固件开发 · 文档 ID 106 · 原始页面

固件开发

本篇文章主要讲述了如何在平台进行“固件开发”，本章节仅面向直连接入。关于如何设计产品的功能定义，请参考《⽐亚迪智能设备开放接⼊协议》和《BYD乘用车IoT设备OTA升级协议》。

注意：产品功能定义会直接影响后续的固件OTA，请在开发之前务必参考《⽐亚迪智能设备开放接⼊协议》和《BYD乘用车IoT设备OTA升级协议》完成产品功能定义的设计。

1. 前提条件

1）在比亚迪生态开放平台进行“企业开发者认证“且被审核通过，请参考“开发者注册认证-4.1 企业开发者认证”。

2）登录比亚迪生态开放平台。

3）在平台成功创建产品。

4）明确产品功能定义设计。

2. 操作步骤

2.1 选择产品方案/协议

开发固件之前务必仔细阅读《⽐亚迪智能设备开放接⼊协议》和《BYD乘用车IoT设备OTA升级协议》完成产品功能定义的设计。

2.2 进行产品功能开发

明确设备升级方案“AB分区升级”、“备份升级”（建议升级方案优先选择AB分区升级）或者“不支持OTA”，进行对应的固件开发，在开放平台「管理中心 - 产品管理 - 产品清单 - 固件开发」中，按照固件版本文件命名规则，上传固件版本，如下图 2-1。固件开发完成后，需要进行固件的自测，比亚迪生态开放平台提供了“短距IoT协议测试助手”应用，开发者可以通过开放平台账号登录APP进行功能验证，具体操作方式参见：产品自测。

图 2-1 固件开发-提交自测前

其中，固件版本号（对应BLE协议中字段Firmware Revision String）需要符合格式：主版本号.子版本号.阶段版本号.日期，例如：1.0.0.20250825。

主版本号：当功能模块有较大的变动，比如增加多个模块或者整体架构发生变化。

子版本号：功能有一定新增或变化，比如增加了某些权限控制等。

阶段版本号：一般是Bug修复或是一些小的变动，要经常发布修订版，时间间隔不限。

固件版本执行“提交自测”后，如下图 2-2， 您可以在本界面下载“短距IoT协议测试助手”App，在手机端完成BLE测试、OTA测试（如支持OTA）、OTA循环测试（如支持OTA）。如果您需要修改固件版本，可以点击按钮“修改固件包”重新上传固件版本。当您的“短距IoT协议测试助手”App成功完成所有测试，再点击按钮“下一步”，即可转入下个操作步骤：版本自测，在“版本自测”界面中，上传手机App的所有测试报告。

注意：在生态开放平台“固件开发”步骤提交的固件版本，需要和“版本自测”时用“短距IoT协议助手App”测试的固件版本保持一致。

图 2-2 固件开发-提交自测后

3. 后续操作

3.1 产品状态

产品自测过程中默认状态为“开发中”，如果固件审核通过产品并发布版本，则状态会变成“已上线”。

3.2 产品版本迭代

物模型上线后，如需迭代功能：

1）迭代新版本

  • 下载原有物模型文件。
  • 对原有物模型文件进行编辑，添加新功能，版本修改描述、备注。

2）申请新版本上线

  • 迭代版本的功能定义如需上线，需要同步迭代固件版本。
  • 在平台上传固件包后，通过“短距IoT协议测试助手”，对相应的固件包进行测试，上传对应的测试报告然后进行审核，审核通过后，进行发布，产品状态会自动变成“已上线”。
