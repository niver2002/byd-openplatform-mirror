2026比亚迪智能座舱设计大赛权益说明

1. 参赛作者或未成年参赛作者监护人同意授予比亚迪合理范围内免费使用参赛者信息（包括姓名、学校、联系电话等）、投稿作品信息（包括作品名称、作品封面、作品说明等）以及参赛作品，以用于本次赛事活动的线上及线下展示、宣传等活动。

2. 对于参赛者创作、上传的参赛作品，比亚迪在赛事期间享有在全球范围内对全部参赛作品免费进行宣传、展示、复制、传播、公开的权利，展示时将署名作者姓名。参赛者理解并同意，对于参赛者创作、上传的参赛作品，比亚迪或比亚迪关联公司有权免费将上述参赛作品及相关内容用于商业或非商业用途或形成衍生作品，包括对参赛作品及相关内容及其衍生作品在全球范围内进行使用、修改、复制、发行、出租、展览、表演、放映、改编、翻译、汇编或制作、申请获得知识产权保护等，参赛作品及相关内容本身及其衍生产品的知识产权及后续申请获得的其他知识产权保护（如有）均免费归属于比亚迪或比亚迪关联公司，这些参赛作品及相关内容本身及其衍生产品可以被比亚迪或比亚迪关联公司免费用于网站、电子杂志、杂志、刊物、海报、公众号文章、APP小程序、车机系统或其他媒介渠道。比亚迪或比亚迪关联公司可与参赛者另行签订知识产权相关协议约定具体事宜。

3. 比亚迪有权对获奖作品进行版权登记，若获奖作品已完成版权登记，作者或未成年参赛作者监护人监护人需配合比亚迪完成转让登记工作。

4. 若比亚迪需对获奖作品进行进一步完善、开发或设计产品落地，获奖作者需协助配合，并按要求提供作品源文件。

5. 作品一经提交，将视为参赛作者或监护人同意并遵守本权益说明及比赛相关规定。若获奖作品在商业使用中其著作权存在争议，比亚迪不承担因作品侵犯第三方权利而产生的法律责任，获奖作品的参赛作者或未成年参赛作者监护人承担全部法律责任，包括不限于比亚迪因参赛者原因产生的经济损失、名誉损失等。

6. 如果获奖作者或未成年参赛作者监护人放弃履行相关版权转让或授权义务，则视为主动放弃相应奖项，比亚迪将在未获奖参赛作者中选择一名替补作为获奖作者，原获奖作者或或未成年参赛作者监护人无需承担额外损失。
