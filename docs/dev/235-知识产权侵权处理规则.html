知识产权侵权处理规则

来源：营销渠道 / 规则中心 / 知识产权侵权处理规则 · 文档 ID 235 · 原始页面

知识产权侵权处理规则

一、概述
1.1 目的

为规范比亚迪商城第三方商家的知识产权保护机制，维护权利人和商家的合法权益，特制定本规则。

1.2 适用对象

本规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。

二、基本概念

2.1 侵权投诉：指投诉人认为比亚迪商城内第三方商家销售的商品、提供的服务或相关展示内容涉嫌侵犯其知识产权，即专利权、商标权、著作权等，而发起的维权申请。

2.2 投诉人：指提出知识产权侵权投诉的自然人、法人或其他组织。

2.3 被投诉人：指投诉人认为并明确指出的，通过比亚迪生态开放平台引入且在比亚迪商城经营的商品或服务侵犯其知识产权的第三方主体。

2.4 比亚迪商城作为网络服务提供者，将依法履行相关义务。任何虚假投诉或滥用投诉权利的行为，均需承担相应法律责任。如对比亚迪商城造成损失，比亚迪商城保留追偿权利。

三、投诉材料要求
3.1 投诉材料要求

投诉人需提供以下材料：

材料类型材料要求
身份证明文件①自然人：有效身份证明文件；②法人/其他组织：有效期内的营业执照、法定代表人身份证明③代理人（如有）：代理人有效证件、授权委托书等。
权属证明基于被投诉知识产权的类型提交相应的证明材料：①专利权：专利权证书或专利授权文件；技术特征或外观特征对比说明等材料。②商标权：商标注册证或商标授权合法凭证；商标对比说明等材料。③著作权：著作权权属证明（如著作权证书、作品首次公开发表或发行日期证明材料、创作手稿、权威机构签发的作品创作时间戳、作品备案证书）；著作权授权凭证；作品对比说明材料。
授权材料（如有）如投诉人不是权属证明材料中的权利人，需说明投诉人与权利人的关系，并提交材料进行佐证（知识产权权利人授权委托书、关系公证书、授权许可合同等）。
侵权事实证明材料争议商品 / 服务构成侵权的证明材料（例如律所出具的侵权评估报告、内容近似对比文件等）、争议商品或服务名称、争议商品链接。
明确诉求具体注明投诉人的核心诉求。
其他证据（如有）①权利稳定性证明材料。②行政司法机关针对纠纷的判决书。
四、投诉处理程序
4.1 材料提交

投诉人需通过联系邮箱openplateform@byd.com提交完整投诉材料。

4.2 处理流程

（1）比亚迪商城在收到投诉人提交的投诉材料后，将及时对材料进行审查，对被投诉人及相关商品采取屏蔽、下架、断开链接等必要措施，并将侵权投诉通知转送被投诉人。

（2）被投诉人在收到投诉通知后，可向比亚迪商城提交不存在侵权行为的声明，声明应当包括不存在侵权行为的初步证据。初步证据包括但不限于以下内容：

材料类型材料
被投诉人信息企业营业执照
权属证明或授权材料基于被投诉知识产权的类型提交相应的证明材料：①专利权：专利权证书或专利授权文件；技术特征或外观特征对比说明等材料。②商标权：商标注册证或商标授权合法凭证；商标差异对比说明等材料。③著作权：著作权权属证明（如著作权证书、作品首次公开发表或发行日期证明材料、创作手稿、权威机构签发的作品创作时间戳、作品备案证书）；著作权授权凭证；作品差异对比说明材料。
答辩理由说明被投诉商品或服务不侵犯投诉方所主张权利的材料：①被投诉人已取得对应知识产权授权的证明材料。②争议商品 / 服务未构成侵权的证明材料（含律所出具的侵权评估报告、内容不近似对比文件等）。③投诉方权利稳定性存疑的相关证据。④行政或司法机关纠纷处理文书（如案件受理通知书、行政处理决定书、司法判决书等）。

（3）在收到被投诉人提交的材料后，比亚迪商城将被投诉人的相关声明与相关材料转送投诉人，并告知该投诉人可以向主管部门发起投诉或向人民法院起诉。比亚迪商城在被投诉人声明送达投诉人十五日内，未收到投诉人已经投诉或起诉通知的，将及时终止所采取的措施（明显侵权的情况除外）。

五、双方权责

5.1 投诉双方应保证所提供材料的真实性、准确性和合法性。

5.2 比亚迪商城有权根据处理需要，将相关材料提交第三方专业机构进行评估。

5.3 比亚迪商城将在法律允许范围内公示相关处理信息。

5.4 投诉人可主动撤回投诉，逾期未补充材料视为自动撤回。

5.5 因材料不全或不符合要求导致的投诉不成立，比亚迪商城不承担责任。

5.6 投诉双方应在首次投诉时提供完整证据材料，不得在后续程序中要求比亚迪商城对新增证据承担责任。

六、附则

6.1 规则变更：比亚迪商城有权根据业务需要或法律法规变化随时调整本规则。调整后的规则通过比亚迪生态开放平台向商家公示后生效。如商家不同意变更，可书面提出异议并停止使用相关服务；若商家在变更生效后继续使用服务，即视为接受变更后的规则。

6.2 生效时间：本规则于2026年1月1日首次发布，自2026年1月1日起正式生效。
