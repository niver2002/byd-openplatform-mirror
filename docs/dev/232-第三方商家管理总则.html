第三方商家管理总则

一、概述
1.1 规则概述

本规则为约定第三方商家在比亚迪商城从事经营活动基本权利和义务的总体规定，商家还应同时遵守与比亚迪商城所签订的各项协议，以及比亚迪商城针对第三方商家发布的各管理细则。

1.2 适用对象

本规则适用于在比亚迪商城向购买者提供商品或服务的第三方商家。“第三方商家”指通过比亚迪生态开放平台引入，并在比亚迪商城经营商品或服务的第三方主体。

二、入驻管理
2.1 资质要求及审核

第三方商家应为依法设立、经合法登记并领取营业执照、取得相关经营许可并有效存续的法人、非法人组织或个体工商户。第三方商家在比亚迪商城的经营活动应符合其登记的经营范围。商家在申请入驻时应提供比亚迪商城要求的全部资质文件，并保证所提供资料的真实性、准确性和完整性。如商家经营执照发生变更，应当在3个工作日内将变更情况报送比亚迪商城；如商家其他资质面临失效，商家需于失效前30天及时对资质信息进行更新。

2.2 协议签署

资质审核通过后，商家应签署商务合作协议、比亚迪生态开放平台相关协议等，并承诺遵守比亚迪商城发布的全部管理规定和要求，包括但不限于合同附件、公告、通知、邮件等形式的文件。

2.3费用缴纳

第三方商家需按照实际经营类目缴纳相应的保证金，具体标准详见《保证金管理规则》。

三、经营管理
3.1 商品质量保障

3.1.1 第三方商家应保证其销售的商品符合国家相关质量标准，不存在危及人身财产安全的不合理风险。如发现商品存在质量问题或其他可能造成消费者损失的问题，第三方商家应立即停止销售并在3个工作日内向比亚迪商城报备。

3.1.2 比亚迪商城有权对第三方商家销售的商品进行定期或不定期的质量抽查，商家应积极配合并承担相应费用。

3.1.3 如第三方商家销售的商品侵犯其他主体合法权益，商家应承担全部法律责任并赔偿比亚迪商城因此遭受的损失。

3.2 物流配送

第三方商家应遵守比亚迪商城物流管理规定，在规定时效内完成发货并及时上传物流信息，确保配送服务质量。

3.3 售后服务

3.3.1 第三方商家应按照国家相关规定和比亚迪商城要求承担商品售后服务责任。

3.3.2 对于需要上门安装的商品，第三方商家应提供完善的管理方案。

3.3.3 第三方商家应承担保修期内商品修理等服务，并在商品详情页面公示服务信息。

3.3.4 第三方商家应设立专门的服务接口人和服务热线，及时处理消费者投诉和咨询。

3.3.5 第三方商家应按要求提供完整的商品服务策略、培训材料和常见问题解答。

3.4 营销推广

3.4.1 第三方商家使用比亚迪商城的推广服务应遵守平台相关规定，并确保在营销物料中清晰注明售后服务联系方式。

3.4.2 第三方商家保证在平台发布的所有信息真实准确，不包含虚假和欺诈性内容。

3.4.3 第三方商家在比亚迪商城之外发布涉及比亚迪品牌相关信息的推广内容，需事先经过平台审核。

3.5 信息安全保护

3.5.1 第三方商家应严格遵守国家网络安全和个人信息保护相关法律法规。

3.5.2 第三方商家收集、使用用户个人信息应当遵循合法、正当、必要原则，并采取有效措施保障信息安全。

3.5.3 如因第三方商家信息安全管理不善导致数据泄露等安全事件，第三方商家应承担全部责任。

四、附则

4.1 规则变更：比亚迪商城有权根据业务需要或法律法规变化随时调整本规则。调整后的规则通过比亚迪生态开放平台向商家公示后生效。如商家不同意变更，可书面提出异议并停止使用相关服务；若商家在变更生效后继续使用服务，即视为接受变更后的规则。

4.2 生效时间：本规则于2026年1月1日首次发布，自2026年1月1日起正式生效。
