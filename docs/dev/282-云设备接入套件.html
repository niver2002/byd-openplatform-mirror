云设备接入套件

来源：开发套件 / AIoT套件 / 云设备接入套件 · 文档 ID 282 · 原始页面

云设备接入开发套件

1. 云设备接入示意图

比亚迪为云设备的第三方企业开发者，提供加入比亚迪IoT云的方式，实现比亚迪车机远程查看和控制云设备。如下图 1-1 云设备接入示意图。

  • 近场：云设备和车机通过BLE协议，以及比亚迪IoT云和云设备私有云交互完成首次鉴权；
  • 远场：通过比亚迪IoT云和云设备私有云交互，DiLink车机获取云设备在远场的状态，显示在车机大屏，并且支持用户通过车机大屏、车机语控、快捷指令操控云设备；

图 1-1 云设备接入示意图

2. 云设备接入协议

开放平台向签署AIoT业务协议的企业用户开放《比亚迪智能云设备接入协议》。用户前往【管理中心-AIoT服务平台-开发协议】即可看到该云设备接入协议。

3. 云设备接入流程

开放平台为云设备接入提供了web端接入流程，以及测试环节。在完成企业资质认证并签署AIoT业务协议后，前往【管理中心-AIoT服务平台-产品接入】产品清单，创建产品时接入方式选择“云设备接入”，选择要接入比亚迪IoT云的云设备产品类型，如图 3-1，分别创建不同的云接入产品，如滑板车，创建产品时接入方式选择“云设备”，然后前往应用管理和云对接配置，完成对应的应用配置和授权信息配置。

3.1 创建产品

  • 如果现有产品类型不能满足您的需求，请及时联系接口人添加类型，或者提交工单。
  • 接入方式选择“云设备”。
  • 关联应用时需要选择【管理中心-AIoT服务平台-产品接入-应用管理】中已经存在的应用，如果没有创建需要的应用，可以点击链接去创建应用，如下图 3-1。

图 3-1 创建产品-云设备接入

3.2 应用管理

在应用管理创建应用时，开发者填写三方云的移动应用或服务器应用的名称和包名，平台会自动生成App ID和App Secret。App ID和App Secret用于三方云向比亚迪IoT云推送设备信息的协议字段，具体可以参考协议《比亚迪智能云设备接入协议》的2.3章节。如下图 3-2 创建应用界面，图3-3 创建完应用的详情界面。

图 3-2 应用管理-新建应用


图 3-3 应用管理-应用详情


3.3 云对接配置

云对接配置包括4个步骤，如下图 3-4。其中在双方调试阶段，开发者需要配置“开发者OAuth(测试)”，里面包含一系列OAuth2相关授权信息；同理，节点“开发者OAuth(生产）”需配置正式环境的相关授权信息。可以参考协议《比亚迪智能云设备接入协议》的1.2章节方案流程图。

图 3-4 云对接配置的流程图
