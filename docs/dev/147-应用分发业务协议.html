本协议由协议正文及目前以及将来可能公示于比亚迪生态开放平台（以下简称“开放平台”或“本平台”）的各项有关应用分发业务的规则所组成（例如《比亚迪应用分发业务接入指南》）。如您对本协议有任何疑问，可通过我们的官方邮箱（openplatform@byd.com）与我们联系，我们将根据您的要求为您进一步解释和说明相关内容。

1.定义

除非双方另有书面约定，下列术语在本协议中的含义为：

1.1“比亚迪应用分发业务”：是指通过本平台，将开发者开发的符合要求的应用程序在比亚迪应用市场向终端用户进行推广、投放、下载和安装的服务，本服务涵盖从应用开发、应用审核、应用上架发布、用户触达到安装转化的全过程。

1.2“应用分发业务开发者”：是指已在本平台完成在线注册并通过开发者认证，签署了本协议及附加条款的开发者。

1.3 “应用分发业务服务包”：是指比亚迪向开发者提供的与应用分发业务相关的软件、代码、API及其他文档、工具等的总称。

1.4 “API”：即Application Program Interface，是指比亚迪提供给开发者的应用程序开放接口。

1.5 “用户”：是指所有直接或间接使用开发者上架或更新至比亚迪应用市场平台上应用的用户。

2.服务内容

“比亚迪应用分发业务”是本平台面向个人/企业开发者所提供的功能及服务。通过本平台，我们向您提供的应用分发业务服务包以及其他资料，你可以通过前述内容完成应用注册、应用开发、版本信息完善、应用提交、应用审核、应用发布等操作。(详见本协议下“开发流程及规范”章节)。请您留意。如您未完成或未通过应用审核、未配合我们进行应用发布等工作，您自行开发的应用将无法在比亚迪应用市场上架。

您理解并同意，本服务可能因适用场景和技术条件的变化而发生调整，您所开通和可使用的场景以本平台显示的界面提示为准，请您留意平台各模块的具体服务内容并在仔细阅读相关使用规则后视需选用。

3.开发流程及规范

3.1 开发者资格

请您留意，您使用本服务前，请确保您满足下述开发者资格条件：您已注册开放平台账号并通过个人/企业开发者认证，并满足以下要求：

（1）如您为企业的，则应在中华人民共和国领域内合法登记注册；如您为自然人的，应为具有法定完全的民事行为能力和民事权利能力；

（2）您具备与我们订立本协议所需要的资质或许可；

（3）根据适用的法律，您未被禁止接受本服务；

您应提交真实准确的信息、资质材料或证明等，我们有权审查您是否满足上述要求，但并不因为我们的审查，而减轻您对其提交的信息的完整性、真实性、合法性的保证责任，由此产生的一切责任和后果仍由您单独承担。

3.2 接入开发

（1）接入开发指您通过本平台的各项指引和我们提供的应用分发业务服务包，依次自行完成应用注册--应用开发与自测-版本信息完善与应用提交的过程。在接入开发阶段您可以获得平台已开放能力和服务的支持。在应用开发环节，如您涉及调用我们提供的API接口的，我们会在应用审核阶段对此进行审核。当您完成应用开发与自测后，您需如实填写应用相关信息，包括但不限于应用信息、推广信息、资质信息、自检信息、联系人信息，并提交应用审核，提交应用审核视为您已提交应用上架申请。接入开发的具体步骤和详细事项，具体请参考《比亚迪应用分发业务接入指南》。请您留意，接入开发的应用需满足本协议及本平台审核指南和相关规则，包括但不限于应用功能、兼容性、性能、稳定性测试标准；网络安全技术要求；数据安全技术要求、特殊行业资质要求等，请您及时在本平台“文档中心-平台协议-应用分发业务服务”板块查看全部规则要求并确保全部遵守，否则您开发的应用可能无法通过我们的应用审核，由此产生的责任，由您自行承担。我们提醒您及时查看并留意应用分发业务规则更新版本，遵守相关要求。接入开发如涉及收费服务的，需缴纳相应的费用后方可享受相应的服务。

（2）请您留意，完成应用接⼊开发不代表可直接上架或发布应用，应用上架或发布需要通过我们的应用审核等后续流程。

3.3 应用审核
