产品卖点填写规范

产品卖点填写规范

新广告法实施后，对内容问题的处罚极限由原来的退一赔三变更为罚款二十万元起。产品卖点撰写应严格按照广告要求进行。以下提炼相关卖点撰写规范，请严格执行。

1. 一定不能出现的内容，出现直接驳回

内容请勿出现反动及政治相关的内容。

1.1 表示权威性的禁忌词

  • 国家XXX领导人推荐、国家XX机关推荐、国家XX机关专供、特供等借国家、国家机关工作人员名称进行宣传的用语。

       错误示例：国家XX部门指定智能IoT产品

  • 质量免检、无需国家质量检测、免抽检等宣称质量无需检测的用语。

       错误示例：xxx儿童座椅，中国驰名商品

  • 首个、首选、全球首发、全国首家、全网首发、首款、首家、独家、独家配方、填补国内空白等用语。

       错误示例：xxx智能眼罩，全网首发/独家首发

1.2 包含“最”及相关词语

  • 最、最佳、最具、最爱、最赚、最优、最先进、最优秀、最好、最大、最大程度、最高、最高级、最高档、最奢侈、最低、最低级、最低价、最底、最便宜、时尚最低价、最流行、最受欢迎、最时尚、最聚拢、最符合、最舒适、最先、最先进、最先进科学、最先进加工工艺、最先享受、最后、最后一波、最新、最新科技、最新科学等含义相同或近似的绝对化用语。

       错误示例：

           xxx扫地机器人，清扫能力最强的扫地机

           xxx摄像机，价格最便宜，性能最强

           xxx净水器，净水器品类最受欢迎的产品

1.3 包含“一”及相关词语

  • 第一、中国第一、全网第一、销量第一、排名第一、唯一、第一品牌、NO.1、TOP.1、独一无二、全国第一、一流、一天、仅此一次（一款）、最后一波、全国X大品牌之一等用语。

       错误示例：

           xxx扫地机器人，第一款支持扫拖一体的机器人

           xxx摄像机，全网销售第一，人气第一

           xxx净水器，一流的净水能力

1.4 包含“级/极”及相关词语

  • 国家级（相关单位颁发的除外）、全球级、宇宙级、世界级、顶级（顶尖/尖端）、顶级工艺、顶级享受、极品、极佳（绝佳/绝对）、终极、极致等用语。

       错误示例：

           xxx扫地机器人，顶级工艺，打造行业标杆

           xxx摄像机，极佳的视频清晰度，实时监控

1.5 表示品牌地位的相关词语

  • 王牌、领袖品牌、世界领先、遥遥领先、领导者、缔造者、创领品牌、领先上市、至尊、巅峰、领袖、之王、王者、冠军等用语。

       错误示例：

           xxx扫地机器人，扫地机行业的领导者，销量遥遥领先

           xxx摄像机，冠军之选，巅峰品质

1.6 表示绝对、极限且无法考证的词语

  • 绝对值、绝对、大牌、精确、超赚、领导品牌、领先上市、巨星、著名、奢侈、世界/全国X大品牌之一、世界级、金牌、名牌、优秀、世界领先、顶级工艺、王牌、销量冠军、极致、永久、王牌、掌⻔人、领袖品牌、绝无仅有、史无前例、万能、100%、国际品质、高档、正品等虚假或无法判断真伪的夸张性表述词语。

       错误示例：

           xxx空气净化器，空净行业的领导者，销量遥遥领先

           xxx颈部按摩仪，冠军之选，巅峰品质

1.7 激发消费者抢购心理的表述

  • 秒杀、抢爆、再不抢就没了、不会再便宜了、错过就没机会了、万人疯抢、抢疯了、售罄、售空、史上最低价、错过不再/错过即无、全⺠疯抢/抢购、免费领、0首付、零距离、价格你来定等激发抢购心理的词语。

       错误示例：

           xxx智能床垫，限量首发，再不抢就没了

           xxx车载香氛，史上最低价，全⺠抢购

2. 确保卖点描述的功能，与实际功能一致

产品卖点从产品特色中选取提炼，需确保产品卖点为该产品的主要特色，描述需与产品功能一致。建议与产品站购买详情⻚内的产品卖点功能保持一致。

卖点限制字数为100个汉字字符，请尽量精简语言，提炼重要信息。

举例：

产品：

  • 倍轻松See7眼部按摩器

卖点：

  • 支持冷敷和热敷，内置14个独立振点按摩头，三种按摩模式可选：美眼模式、护眼模式和睡眠模式。


产品：

  • 倍轻松N6miniPro颈部按摩仪

卖点：

  • 3D立体按摩头，42°C恒温热敷，5D梅花滚轮，艾灸碳发热技术，红光强渗透，温暖看得见。


产品：

  • 好孩子CS008儿童安全座椅

卖点：

  • 双向安装的坐躺调节式座椅，适合0-7岁儿童适用，采用三/五点式安全带固定，具备可调节靠背角度和布套拆卸清洗功能。

3. 确保卖点格式、内容的正确性

  • 卖点限制字数为100个汉字字符，请精简语言；
  • 请检查内容的正确性，请勿出现错别字；
  • 提及数字部分，请使用阿拉伯数字；

   举例：

       正确：10大新功能

       错误：十大新功能

  • 内容请勿涉及政治、反动等敏感信息；
  • 标点：中文请使用汉字字符标点；

    举例：

       正确：身材小巧节省空间。400加仑大流量直出纯净水，增强版复合滤芯RO反渗透技术，深层净水。

       错误：身材小巧节省空间.400加仑大流量直出纯净水,增强版复合滤芯RO反渗透技术,深层净水.

  • 请勿使用网络用语及网络热梗；

   错误示例：

       美的空气净化器，yyds

       影石Insta360GO3S，City不City

       美的扫地机，船新版本
