赛道设置

大赛共设三个赛道：座舱交互前瞻赛道、座舱主题赛道、亲子壁纸赛道。 以下赛道详情取自官方前端数据模块。

座舱交互前瞻赛道

探索未来智能座舱的交互方式，以创新的设计理念重新定义人车交互体验。鼓励参赛者运用前沿技术，打造具有前瞻性的交互方案。

作品要求

  • 作品需包含至少3个交互场景设计
  • 需提供交互流程图和界面效果图
  • 鼓励提交动态演示视频（MP4格式）
  • 作品需保存为RGB模式，支持JPG/PNG格式

提交规范

  • 主视觉概念图（必选）
  • 桌面效果图（必选）
  • 应用中心效果图（必选）
  • 创意交互视频（建议提交）
  • 作品创作说明（100字以内）

座舱主题赛道

为比亚迪智能座舱设计主题方案，涵盖壁纸、图标、熄屏、语音形象等多个设计模块，打造统一的座舱视觉体验。

作品要求

  • 作品需至少选择3个模块进行设计（其中壁纸、图标为必选）
  • 模块包括：壁纸、图标、熄屏、语音形象、开机动画、仪表盘等
  • 作品需保存为RGB模式，支持JPG/PNG格式
  • 鼓励上传MP4格式视频展示动效

提交规范

  • 主视觉概念图（必选）
  • 桌面效果图（必选）
  • 应用中心效果图（必选）
  • 创意交互视频（可选）
  • 作品创作说明（100字以内）

亲子壁纸赛道

以亲子互动为主题，设计温馨有趣的座舱壁纸作品。鼓励家长与孩子共同参与，发挥创意，打造充满爱与想象力的视觉作品。

作品要求

  • 作品需以亲子互动为主题
  • 壁纸需适配车机屏幕分辨率
  • 作品需保存为RGB模式，支持JPG/PNG格式
  • 未成年人参赛需监护人签署授权协议

提交规范

  • 壁纸设计图（必选）
  • 创作说明（100字以内）
  • 监护人授权协议（未成年人必选）

常见问题
Q1： 谁可以参与？
本届大赛设 3 个赛道。座舱交互前瞻与座舱主题面向全球在校大学生、专业设计师及设计爱好者；亲子壁纸仅限 3-14岁青少年儿童（须由法定监护人代为报名并签署同意书）。严禁参赛者提交虚假身份信息、冒用他人身份参赛。恕不接受已在其他或往届活动中投递或公开刊物上已发表的的作品参与评选。

Q2： 如何报名？
通过比亚迪生态开放平台，按照系统提示进行报名，填写基础信息并选择您的意向赛道。

Q3： 如何投递作品？
登录比亚迪生态开放平台大赛主页面，在作品提交截止日期前，点击【提交作品/我的作品】，按照系统提示投递作品。

Q4： 是否有作品数量上限？
亲子壁纸赛道需以家庭为单位参赛，每个家庭最多投递 3 份作品。
座舱交互前瞻赛道与座舱主题赛道，个人参赛时每个赛道最多投递 3 份作品；组队参赛时每人以第一作者身份每个赛道最多投递 3 份作品（备注：仅在校大学生可以组队参赛，默认报名人为第一作者）。

Q5： 可以将 1 件作品投递至多个赛道吗？
不可以，请严格按照赛道要求投递作品。

Q6： 如何查看已投递的作品？
登录大赛官网，进入「我的作品」页面，可查看自己所上传的作品。

Q7： 报名成功后是否还可以修改报名信息？
报名成功后仍可修改报名信息、修改上传作品。但请在作品提交截止时间前完成所有修改，以确保提交的最终版本符合要求。

Q8： 如果我错过了常规截止日期，是否可以通过邮箱openplatform@byd.com补交？
作品提交截止时间为2026年11月30日北京时间23:59:59，此时间过后组委会将不再接收作品。错过截止日期无法通过任何渠道（包括邮件）补交。

Q9： 如何查询参赛进度与获奖结果？
可通过比亚迪生态开放平台查询参赛进度，获奖结果将在评审结束后统一在生态开放平台、比亚迪官方公众号、比亚迪官方小红书账号等平台公示。

Q10：查看大赛 用户协议、 隐私政策、 参赛规则、 获奖通知、 权益说明、 儿童隐私保护说明。
